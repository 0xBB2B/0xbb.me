# 当前角色造型

- 默认主角：原黑装，高2.4单位，造型与普通步态不改。
- A主角：银白高马尾、黑蝴蝶结、露肩黑长裙；可在灯塔旁与黑装带特效互切。
- B迎宾者：金发、黑挂脖上衣、浅色外套、百褶裙。已用于正式NPC，不参与主角切换。

# FUBUKI_BB · 雨夜便利店个人主页

[0xbb.me](https://0xbb.me) 的个人主页源码：一个放在展示台上的雨夜日式便利店街角微缩模型。点展示台上的铭牌，镜头会沿着街角一段段移动，边滚动边看个人资料。

## 体验与操作

| 操作 | 效果 |
| --- | --- |
| 拖动 | 旋转整体视角 |
| 滚轮或双指 | 缩放整体视角 |
| 右键或双指 | 平移整体视角 |
| 点击铭牌 | 进入资料视角 |
| Tab 聚焦「查看资料」按钮后回车 | 进入资料视角 |
| 资料视角滚动、上下滑动或按 PageDown / PageUp / 方向键 / 空格 | 一次翻一段，翻页动画约 1 秒 |
| 资料视角按 Esc 或点左上角「返回全景」 | 回到整体视角 |
| 资料视角右上角点 EN / 中 | 切换语言 |

## 画面与动效

- 雨只下在展示台底座上方
- 地面有水洼倒影与波纹
- 雨滴落地会溅起水花
- 屋檐边缘有滴水
- 便利店招牌闪烁
- 便利店自动门会开关
- 停在路边的保时捷双闪灯亮着
- 路口信号灯按 20 秒一个周期切换
- 铭牌边框有呼吸般的微光

电脑上默认开启高画质效果；手机或帧率不足时会自动关闭地面倒影，保证画面流畅。

## 没有 3D 时

加载页上点「先看资料」，不用等三维场景，直接进入资料视角。三维场景加载失败时，页面会自动切到资料视角，并提示「3D 场景无法加载」。

## 本地开发

```bash
bun install --frozen-lockfile
bun run dev      # 启动开发服务器
bun run build    # 生成 dist 静态产物
bun test         # 跑全部测试
```

浏览器相关测试用本机 Chrome 的无窗口实例驱动，可通过环境变量 `PORTFOLIO_CHROME_PATH` 指定 Chrome 可执行文件路径。端到端测试和发布检查读的是 `dist/` 里的构建产物，跑之前要先执行一次 `bun run build`。

## 部署

推送到 `main` 分支后，GitHub Actions（见 `.github/workflows/deploy.yml`）会安装依赖、执行 `bun run build`，把生成的 `dist/` 发布到 GitHub Pages。

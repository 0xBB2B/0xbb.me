## 2. 业务规则
- graphics-runtime/C-4：在记录了设备、操作系统、浏览器版本的桌面环境中，系统应在 1440×900 视口、图形加载完成、页面保持可见的连续 30 秒行走采样期间，使帧间隔 P95 不超过 33.4 ms；采样包含跨场景过程，不剔除慢帧。
### graphics-runtime/AC-4 桌面帧间隔 ← C-4
- 触发: 操作 记录桌面运行环境，在含场景交界的道路连续行走并录制 30 秒帧时间。
- Given: 记录设备型号、操作系统、浏览器版本；视口为 1440×900，图形加载完成，页面可见，采样期间不切换窗口或调整尺寸。
- When: 访客持续行走并经过场景交界，采集完整 30 秒的帧间隔，按由小到大排序取向上取整的第 95% 顺位值。
- Then: 帧间隔 P95 不超过 33.4 ms；保留测量条件与实际数值作为证据，不删除慢帧，也不将该桌面结果标为手机真机性能通过。
- site-entry/C-3：系统应通过命令 bun run build 生成可静态托管的页面与资源；访客浏览主页、交谈、查看看板、切换语言和打开速览不需要账号、服务端存档或独立后端应用。
- site-entry/C-4：如果访客请求 /game/，系统不应呈现或启动节奏光剑游戏；站内导航、作品操作入口和页面信息均不应引导访客启动该功能。
- site-entry/C-5：系统应以 Minecraft 方块三维几何呈现主人公与 NPC，人物不得使用 SVG 或图片纹理；背景、道具、特效、非人物图标及交互 UI 可使用纯矢量 SVG 或程序化几何。成品不得包含或加载 PNG、JPG 等位图素材，原始设计参考与验收截图仅为非发布材料。
- site-entry/C-6：如果本站图形以矢量、三维模型、内联数据或外部资源呈现，系统不得包含 SVG 内嵌图像、Base64 位图、外链位图或改扩展名的位图；浏览器正常屏幕栅格化不视为使用位图素材。

# 术语表

| 锚点 | 定义 | 别名 |
|---|---|---|
| hd2d | 清晰像素角色置于有前中后景、立体布景和光照的世界；像素指画风而非位图格式，不指仅对平面页面施加像素滤镜。 | HD-2D |
| code-artwork | 由绘制代码、程序化几何或纯矢量 SVG 定义的图形，动画由代码驱动；不包含位图文件或嵌入位图，浏览器正常屏幕栅格化不属于位图素材。 | 代码化图形 |
| bitmap-asset | 用作网站图形的栅格图片或精灵表，包括独立文件、编码内联、SVG 包裹和外链形式；非发布的设计参考与测试截图不属于网站素材。 | 位图素材 |
| player | 访客可操控、由代码绘制的全身像素角色，以银白马尾、蓝眼和黑白服装作为辨识特征。 | 主人公 |
| npc | 不由访客操控、通过主动交谈介绍站点主人的场景角色。 | NPC |
| dusk-town | 探索起点，承载个人背景介绍的黄昏城镇。 | 黄昏城镇 |
| tech-workshop | 承载技能介绍的第二个连续场景。 | 科技工坊 |
| starry-gallery | 承载作品介绍的第三个连续场景。 | 星夜展街 |
| interaction-range | 主人公靠近某位 NPC 后，该 NPC 显示交谈提示的区域；只有该范围内可以开启对话。 | 交谈范围 |
| dialogue-segment | 一次翻页所显示的一段介绍；中英文对应段落表达相同主题。 | 对话段落 |
| profile-overview | 无需行走即可直接阅读简介、技能、作品与联系方式的入口，内容与 NPC 介绍一致。 | 资料速览 |
| graphics-unavailable | 浏览器不能初始化图形、图形上下文失效或必要图形资源加载报错的状态。 | 图形不可用 |
| frame-interval | 相邻可见画面帧的呈现时间差，以毫秒计。 | 帧间隔 |
| p95 | 将全部有效采样值由小到大排序后，取向上取整的第 95% 顺位值；不剔除慢帧。 | P95 |

# 资料速览

## 目的
让不操作游戏或无法运行图形的访客直接取得FUBUKI_BB的个人资料与作品入口；个人身份与原住民NPC的世界观故事分开呈现。

## 逻辑
主页提供明显的资料速览入口，不需要先行走或完成对话。
打开后以角色档案开篇，显示用户确认的个人人设图、简介，再展示技能、作品与联系方式，并暂停行走。
资料与技能/项目说明表达相同事实，不虚构履历或成果；NPC台词只讲游戏世界，不冒充主角的自我介绍。
关闭后返回原位置；图形不可用时仍可直接阅读资料，也可关闭回主页选择语言再打开，不要求先恢复图形。

## 约束
- C-1：系统应介绍 FUBUKI_BB 是全栈工程师、系统架构师与 AI Agent开发者，地点为 Tokyo、Shanghai，工作方向包括 AI 工作流、可扩展后端、游戏 SDK 生态与交易平台，不添加未经确认的雇主、客户、奖项或成绩。
- C-2：五项技能写用户会做什么、实现过什么与解决什么问题，不写通用技术百科。AI Agent简洁关联bb-spec和pi-subagent-cluster；Golang为最拿手语言，从零设计包括海外游戏发行SDK框架、网页积分商城的系统；Docker/k8s为所有开发部署基础；海外SDK帮助国内开发商接入各国登录和支付、降低研发成本；支付实践覆盖多国渠道、积分商城在线活动及支付。终端短简介、详情/速览完整说明一致，无等级/分数/百分比评级，不添加用户未确认的量化成果；速览技能每行最多三张，小屏幕减为两列或一列。
- C-3：系统应展示 3 个 ONLINE 作品，每个作品有至少三段说明，内容根据本站实际功能或项目官方README撰写，及下方作品表中对应的介绍、访问与源码入口；站点自身作品介绍应描述 MC-2D 探索主页。
- C-4：系统应提供下方联系表中的 GitHub、LinkedIn、Juejin 和 Email 共 4 个入口，文字或可访问名称能区分其目标。
- C-5：当访客打开资料速览时，系统应在无需行走或 NPC 对话的情况下提供完整资料，暂停行走；关闭速览后回到打开前的位置。
- C-6：如果图形不可用，系统仍应展示相同的简介、5 项技能、3 个作品及 4 个联系入口，不能要求先恢复游戏才能阅读或使用外链。

- C-7：public/profile-full.png仅在资料速览打开时作为HTML人设图加载；桌面左图右文，手机竖屏上图下文，不裁切原比例，不作为NPC或主角纹理。图片加载失败时有清楚占位说明，简介/技能/作品/联系仍完整可读且可关闭，不依赖图片或图形恢复。

## 验收
### AC-1 个人事实 ← C-1
- 触发: 操作 打开资料速览并阅读简介。
- Given: 访客首次进入主页，未操作主人公。
- When: 访客查看个人资料，再与原住民NPC的世界观区分。
- Then: 主角姓名、职业、地点和工作方向符合约束，AI角色称谓为“AI Agent开发者 / AI Agent Developer”；NPC不是FUBUKI_BB，不在世界观里重复主角履历，不出现未经确认的个人成果或雇佣关系。

### AC-2 五项无等级技能 ← C-2
- 触发: 操作 打开资料速览的技能内容。
- Given: 资料速览可访问。
- When: 访客逐项查看技能名称与介绍。
- Then: 顺序和内容与终端一致，准确包含C-2所述用户项目实践、擅长语言和业务价值，而非泛泛定义；AI Agent关联实际项目但不冗述，不虚构数字或评级。

### AC-3 三个作品与链接 ← C-3
- 触发: 操作 阅读作品列表并逐一激活访问与源码入口。
- Given: 资料速览可访问，浏览器允许正常外链导航。
- When: 访客检查 3 个作品的名称、状态、描述及链接目标。
- Then: 3 个作品均为 ONLINE，介绍要点和链接与作品表一致；浏览器导航到对应地址，不以第三方服务的实时可用性作为本站承诺。

### AC-4 四个联系入口 ← C-4
- 触发: 操作 检查并激活 GitHub、LinkedIn、Juejin 和 Email。
- Given: 资料速览可访问。
- When: 访客逐一使用 4 个入口。
- Then: 各入口具有可辨认名称并指向联系表地址；邮件入口使用指定邮件地址，实际是否打开邮件客户端取决于访客设备设置。

### AC-5 无需游戏的阅读与返回 ← C-5
- 触发: 操作 在起点直接打开速览，再在道路中段打开和关闭速览。
- Given: 图形运行正常，访客尚未完成任何 NPC 介绍。
- When: 访客阅读速览，尝试移动并关闭。
- Then: 全部资料无需解锁即可阅读；打开期间人物不移动，关闭后仍处于打开前的位置。

### AC-6 图形故障仍可阅读 ← C-6
- 触发: 操作 禁用所需图形能力或使必要图形资源报错后访问主页。
- Given: 浏览器能加载个人资料，但图形不可用。
- When: 访客阅读资料并检查作品和联系入口。
- Then: 简介、5 项技能、3 个作品、4 个联系入口仍完整可用，不要求恢复游戏或前往 NPC。

### AC-7 人设档案布局 ← C-7
- Given：用户已确认使用profile-full.png，资料速览可访问。
- When：在1440×900、390×844、844×390打开速览，随后阻断图片请求重试。
- Then：只有打开速览才请求图片，桌面/横屏图文并列、竖屏上下排列，图片原比例不裁切，无全页溢出，关闭可用；失败时保留占位和全部文字/链接。

# 中英文切换

## 目的
让中文与英文访客阅读同一份个人介绍，并在切换语言时保持探索连续性。

## 逻辑
每次打开或刷新主页时默认英文，主人公从起点开始。
EN/中按钮仅在主页探索状态显示；任何弹窗打开时，弹窗内外都不显示语言按钮。访客关闭弹窗回到主页后选择中文或英文，再重新打开阅读。
切换覆盖界面提示、NPC 对话、看板摘要与详情、资料速览及故障说明。
主页切换语言不重置主人公位置，不保存跨刷新状态；弹窗沿用打开前选择的语言，NPC关闭后重读从第一页开始。

## 约束
- C-1：当访客首次进入或刷新主页时，系统应默认使用英文并从探索起点开始，不恢复上次刷新前的语言或位置。
- C-2：当访客切换中文或英文时，系统应同步切换可见界面提示、场景名称、NPC 介绍、看板摘要与详情、资料速览和故障说明；技术、项目、品牌名称和链接目标保持其原有身份与含义。
- C-3：语言选择仅在没有阅读弹窗的主页进行。弹窗打开后页面上不显示任何EN/中或语言切换控件，沿用打开前所选语言。关闭、切语言、重新查看时人物位置不变，仍可查看近处对应内容；NPC重读从第一页开始。
- C-4：图形不可用时自动展示完整资料；可以关闭资料回到主页选语言，再打开速览阅读对应语言的故障说明和完整内容。弹窗里不提供语言按钮，不需要恢复图形即可使用资料与链接。

## 例子
访客以英文阅读Golang详情，关闭后在主页切换中文，再查看Golang；人物仍在终端旁，内容仍是同一技能。阅读期间不显示EN/中按钮。

## 验收
### AC-1 初始语言与刷新 ← C-1
- 触发: 操作 首次进入主页，切换中文并向右走后刷新。
- Given: 浏览器可正常打开主页。
- When: 访客观察初始语言，切换中文、移动后刷新。
- Then: 首次进入和刷新后均为英文，刷新后主人公从起点开始，不恢复先前位置。

### AC-2 双向全量切换 ← C-2
- 触发: 操作 切换中文并阅读迎宾NPC、八块看板及详情和资料速览，再切回英文。
- Given: 主页运行正常，全部内容可访问。
- When: 访客在两种语言下检查提示、场景名、介绍、技能、作品与联系方式。
- Then: 两种语言均覆盖完整内容，不出现未翻译的界面占位文字或丢失介绍；项目与技术名称可使用原名，外链目标不随语言变化。

### AC-3 阅读位置连续 ← C-3
- 触发: 操作 在道路中段选择语言，打开并关闭NPC介绍、技能/项目详情与速览。
- Given: 主人公已离开起点。
- When: 查看弹窗内外是否出现语言按钮，关闭后切语言并重新阅读。
- Then: 弹窗打开时没有语言按钮，主页才可切换；人物不回到起点，技能/项目详情仍属于近处同一对象，NPC重读从第一页开始。

### AC-4 故障阅读仍可切换 ← C-4
- 触发: 操作 在图形不可用的主页上切换中文与英文。
- Given: 浏览器不支持所需图形能力，或必要图形资源加载报错，已显示资料。
- When: 访客关闭资料、在主页切换语言、重新打开资料，并使用一个作品或联系入口。
- Then: 两种语言的故障说明与完整资料均可阅读，外链仍指向对应目标，不依赖游戏恢复。

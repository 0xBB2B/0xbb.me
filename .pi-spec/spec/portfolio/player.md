# 可操控像素主人公

## 目的
让桌面与手机访客操控具有个人设定辨识度的主人公，而不是观看自动移动的立绘。

## 逻辑
主人公默认采用黑装Minecraft方块造型，自然闭嘴、不吐舌，高2.4单位；在灯塔寄语出现的同一区域，可通过带特效的按钮切换黑装与A黑色长裙，只有这两款。
头部、躯干、四肢和马尾以真实方块几何构成，服装与五官以几何色块表现；不使用 SVG 或位图人物。
造型预览与完整行走动画分别验收，不将静态模型移动当作步态完成。
未操作时待机，持续方向输入时沿道路行走，反向输入时转向。
桌面使用键盘，按住Shift配合方向键快跑；触屏使用屏幕按钮保持步行，均可向左返回。
松开输入、失去焦点或进入阅读状态时停止行走。

## 约束
- C-1：系统应默认显示最新黑装参考对应的 Minecraft 方块三维主角，具有银白高马尾、蓝眼、蓝色耳饰、自然闭嘴且无舌头的表情、黑色短外套与短上衣、腰部肤色色块、黑短裤与腰带、单侧长袜、无挂件及挂链的厚底系带靴；身体部件、衣装色块和完整手脚可辨认，不能以 SVG 或位图人物替代。
- C-2：当主人公在待机、向左行走和向右行走之间切换时，系统应展示对应状态与朝向，行走时可见双腿交替迈步，待机时停止迈步，不能以整幅立绘平移代替行走动画。
- C-3：当桌面访客持续按住 A、D、左方向键或右方向键时，系统应分别向左、向右、向左或向右移动主人公，并允许停下或回头，不要求跳跃才能走完全程。
- C-4：当触屏访客持续按住屏幕左行或右行按钮时，系统应向对应方向移动主人公，松手后停止。
- C-5：如果方向输入结束、触屏操作被取消或窗口失去焦点，系统应停止行走；恢复焦点时不得因失焦前的输入继续移动，必须重新操作。
- C-6：在 NPC 对话、看板详情或资料速览打开期间，系统应暂停主人公行走；关闭后主人公仍在打开前的位置，只有重新输入方向才继续移动。
- C-7：如果访客在道路起点向左或在终点向右持续操作，系统应将主人公限制在道路可行走范围内，不使其离开场景或落出道路。
- C-11：默认黑装主角的80%尺寸、高2.4单位和完整造型不变。主角切换按钮与灯塔寄语同时出现/隐藏，在最后1.2单位范围内且没有阅读面板时可用；只在黑装与A黑裙之间切换，B为NPC；按钮右侧不显示造型名字，仅显示切换动作或换装中提示，当前造型放在可访问描述中。切换不重置位置、朝向、语言或画布；有约0.65秒光点聚拢/散开和局部缩放动画，期间暂停移动、防止重复触发，结束后恢复尺寸并清理旧模型资源。减少动态偏好下只做柔和光环渐隐；图形故障能取消切换并打开资料。
- C-12：桌面Shift+A/D或左右键以5.6单位/秒快跑，松开Shift恢复3.2单位/秒步行。快跑手臂和腿的最大摆幅分别约0.78与0.72弧度，步行仍为0.22与0.28；手脚摆动节奏只略快于步行，快跑相位按每移动单位2.6弧度推进，切换有短暂平滑过渡，脚底保持接地。快跑身体上下起伏独立为每完整摆臂周期一次平滑循环，总范围0.025场景单位，腿部小幅接地补偿，不让整身跟随每次落脚抖动；普通步行、移动速度与手脚摆幅/节奏不因此变化。两款主角均支持；失焦、阅读或换装清理输入，不能越过关闭的门或道路端点，触屏按钮不提速。

## 例子
访客按住 D 使白发主人公向右迈步，到 NPC 处按 E 交谈后停住；关闭对话再按 A，人物转向并沿原路向左行走。

## 验收
### AC-1 角色设定可辨认 ← C-1
- 触发: 操作 观察起点主人公的全身造型。
- Given: 最新黑装人物参考已由用户指定，主页与角色模型加载成功。
- When: 访客观察默认主角，并将头部、衣装与腿脚同参考对照。
- Then: 默认是完整的 Minecraft 方块三维人物，可辨认银白高马尾、蓝眼、蓝色耳饰、自然闭嘴无舌头、黑短外套/短上衣、腰部肤色、短裤/腰带、单侧长袜及系带厚底靴，双靴无蓝色挂件、挂链或挂件高光，鞋带、鞋扣、厚底和蓝色耳饰保持可辨；不是 SVG、位图或带矩形背景的图卡。

### AC-2 待机行走转向 ← C-2
- 触发: 操作 先不输入方向，再向右走、松开、向左走。
- Given: 主人公位于道路中段且未打开阅读面板。
- When: 访客执行待机、右行、停止、左行四个动作。
- Then: 待机停止迈步，左右行走时分别面向相应方向并有交替步态；动画切换不使脚底持续上下跳动或将人物变为滑动整幅立绘。

### AC-3 四种键盘输入 ← C-3
- 触发: 操作 分别按住 A、D、左方向键、右方向键后松开。
- Given: 桌面访客位于道路中段，未打开对话或速览。
- When: 访客逐一执行四种方向输入，并沿道路走完全程。
- Then: 移动方向依次为左、右、左、右，可以回头，完成探索不需要跳跃或战斗。

### AC-4 触屏移动 ← C-4
- 触发: 操作 持续按住并松开触屏左右按钮。
- Given: 触屏模式下，主人公位于道路中段。
- When: 访客分别长按左行和右行按钮后松手。
- Then: 主人公在按住期间向对应方向行走，松手后停止，两种方向均可使用。

### AC-5 输入中断不粘连 ← C-5
- 触发: 操作 行走时松开按键、取消触屏操作或切换窗口后返回。
- Given: 主人公正在行走，未到道路边界。
- When: 分别结束键盘输入、取消触屏操作、在按住方向时切换窗口并在外部松手后返回。
- Then: 每种情况下行走均停止；重新聚焦页面时人物不自行移动，重新输入方向后才恢复行走。

### AC-6 阅读暂停移动 ← C-6
- 触发: 操作 分别打开 NPC 对话、看板详情与资料速览，输入方向后关闭。
- Given: 主人公位于道路中段，NPC 对话在可交谈位置开启。
- When: 访客阅读期间尝试键盘或触屏移动，随后关闭阅读面板。
- Then: 阅读期间位置不变，关闭后仍在打开前的位置，不因阅读期间的方向输入而自行继续行走。

### AC-7 道路两端边界 ← C-7
- 触发: 操作 在道路起点持续向左，在终点持续向右。
- Given: 主人公分别到达道路两端。
- When: 访客持续输入越界方向，再输入返回道路的方向。
- Then: 主人公不会走出世界或掉落，反向输入可以正常返回道路。

### AC-11 默认黑装与灯塔换装 ← C-11
- 触发: 操作 打开主页，在相同视口观察人物与房屋，移动、打开资料、切换语言并关闭资料后继续移动。
- Given: 黑装人物与城镇可正常显示，原尺寸基线为高 3 场景单位。
- When: 访客核对人物整体尺寸、脚底位置以及主页和资料面板中的控制，持续移动并刷新。
- Then: 默认黑装尺寸和普通步态不变；灯塔题记出现时按钮也出现，可带特效切换到A、再切回黑装，保持位置/语言/画布，切换期间不走动，返回离开范围后两者同时收起；没有C模型或B主角选项。

### AC-12 Shift快跑与摆幅 ← C-12
- Given：两款主角均可操作，当前无阅读或换装。
- When：用真实键盘分别步行、Shift快跑、松开Shift，随后失焦或打开阅读。
- Then：快跑距离/时间大于步行，手臂和腿摆幅超过步行两倍且脚底接地；恢复步行和停止正常，门和边界仍阻挡，触屏不加速。

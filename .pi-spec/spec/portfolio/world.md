# 连续 MC-2D 世界

## 目的
让访客操控FUBUKI_BB进行连续横向旅程，通过原住民NPC认识世界，通过终端、项目和资料速览了解技能与作品，最后在海边灯塔旁停留。

## 逻辑
访客从黄昏城镇出发，在门前按E或点击开门进入B版地下数据工厂房间；在房间另一端开门离开，进入2版蓝色荧光海。
城镇有一位讲述世界观的原住民迎宾NPC，与主角FUBUKI_BB身份分开；工坊有五块技能终端，海岸上空的三颗星星分别代表三个项目。
镜头随主人公移动，场景、道路和灯光连续过渡；互动提示跟随对应对象，不固定在屏幕底部。

## 约束
- C-1：从左到右依次为黄昏城镇、科技工坊、星夜海岸，共 3 段；只有城镇有迎宾 NPC。工坊五块终端介绍技能，海岸三颗项目星星介绍作品。
- C-2：保留暖光城镇与现有 Minecraft 主角；采用B版地下数据工厂：钢架大厅、发光数据核心、冷却罐、上层维护走廊、服务器机柜和连接管线，以冷白/电蓝和警示橙为主。五项技能名称及简介嵌在背景数据终端的凹入式玻璃屏幕内，屏幕有真实机壳、键盘、状态灯，不以悬浮网页卡片代替。采用2版蓝色荧光海：星空、荧光浪、潮池、木板路与暖光灯塔；没有展馆、橱窗、街区建筑或城市天际线，三颗小型发光星核与柔光芒分别承载项目，不使用扁平五角星和同心圆色块；终点灯塔是海岸唯一建筑。第一章小镇是用户认可的视觉基准，后两章的画面完成度仍需用户确认。
- C-3：数据工厂作为有外墙、顶棚和侧墙的房间连接小镇与海岸；门位于左右侧墙，关闭门面垂直于屏幕。采用约2.6单位宽的上卷工业门，在门框内收起，不横扫人物或墙体；道路在门口收窄并贯穿房间，门槛与0.035脚底高度一致。跨进入口之前不显示室内，房间内不显示小镇/海景，跨出出口后才显示室外；仅开门不提前展示另一侧。保持同一地址、画布和连续人物坐标。
- C-4：门打开后在本次访问内保持开启，两处门口均可停留和反向行走，主人公不重置，可沿相同道路返回；刷新后两扇门恢复关闭。
- C-5：最后项目星星x61至灯塔终点的行走路段从19缩至9.5单位，人物终点x70.5，灯塔随之前移。木板路在人物前方约1单位收边，右侧只延续自然岸边，不继续铺路。人物脚下有支撑并可返回，原起点、人物外观/步态/速度和普通视口镜头保持。

- C-6：距离关闭的门横向不超过1.8单位时，门上方显示“开门进入”或“开门离开”。E/点击主动开启；约0.7秒开门期间人物不移动，不允许重入或打开阅读面板，可切语言；完成后须新的方向输入才能继续走，不自动冲入房间。远处E无效，阅读中不能开门；图形故障中止开门并提供完整双语速览。

- C-7：房间前景有低矮流水线，物料、滚轮、巡检机械臂缓慢运动，不挡住人物与终端。海边流星用细亮头部和两侧/尾端渐隐的细线拖尾，不画宽三角扇面；运动方向与拖尾一致，时间间隔、角度、速度变化，先划过后淡出。另有旋转灯塔光束和海面反光；光束两侧及远端渐隐。水面以连续程序化波纹、月光反射、近岸荧光和远处雾化呈现，不用短横线或大块硬阴影代替水面。遵守减少动态偏好。
- C-8：超宽屏的可玩画面居中，横向比例最多2.4:1，两侧使用配套底色；普通1440×900、390×844、844×390不裁窄。3440×1440、5120×1440下按钮与文字仍对齐场景，不露出地面缺口。
- C-9：在加载阶段按真实室内/室外视图准备着色器与首次绘制，预热未完成时保留完整资料入口，之后才启用移动；预热可在销毁/刷新时安全中断，不留下访问已释放材质的回调。首次进出门以真实可见页面采样，不把该局部结果当作M3整站60FPS达标。
- C-10：三颗项目星星的完整光晕位于实际可见海平线之上，不与水面重叠；水面远端正确收束，地面不在海平线后露出色带。近岸波峰向岸边推进并消散，不向外海倒退。外墙、墙角柱与侧墙接合，不在门与建筑之间露出背景缝隙；门仍位于侧墙门洞内。
- C-11：到达灯塔前最后1.2单位时显示题记和主角换装按钮，两者共用同一出现范围；左上角章节标题始终显示。题记在电脑/横屏的灯塔右侧、竖屏左侧，避开标题、塔身和操作区；不弹窗、不锁定行走，返程离开范围后题记与按钮同时隐藏。中英题记表达“路还很长，追求向往的生活；累了迷茫了记得灯塔，欢迎回来”。

## 例子
访客与迎宾者交谈，到门口主动开门，继续走进房间；在五台终端屏幕内读技能说明，再打开另一端出口走到海边查看项目星星。返程沿已开启的门回到小镇。

## 验收
### AC-1 三段旅程 ← C-1
- 触发：从起点向右走到终点。
- Given：图形加载成功。
- When：依次交谈、查看五项技能和三个项目。
- Then：三个场景顺序正确，只有一位 NPC、五个技能终端和三颗可互动项目星星。

### AC-2 场景辨识 ← C-2
- 触发：在三个场景分别停下观察。
- Given：三段均可访问。
- When：查看实际画面，而不仅检查节点名称。
- Then：城镇暖光保持；数据核心、冷却罐及维护走廊可辨认，五项技能说明在背景终端的屏幕范围内，像数据终端显示内容而非额外卡片；海岸是选定的蓝色荧光海与木板路，三颗星星保留互动，人物和物体有纵深与阴影。

### AC-3 连续跨区 ← C-3
- 触发：向右走过两处交界。
- Given：主人公接近交界。
- When：走到关闭的门前，主动开门，再继续向右进入或离开房间。
- Then：门关闭时无法穿过，上卷门开启时不扫过人物/墙体；仅开门不改变室内外可见范围。跨进后仅看到室内，跨出后才看到室外。门洞与道路对齐，地址和画布不变，无瞬移、门槛高差或道路缺口。

### AC-4 交界往返 ← C-4
- 触发：两处交界各停留并左右往返三次。
- Given：三景可访问，两扇门已主动开启。
- When：停止后交替向左和向右。
- Then：可回到前一景，不重置、不反复切屏。

### AC-5 海边灯塔收尾 ← C-5
- 触发：走到最右端停留，再返回。
- Given：接近旅程终点。
- When：在桌面、手机竖屏和横屏观察终点。
- Then：最后星星到终点为9.5单位，灯塔及荧光海面可见；木板路在人物前方明确结束，右侧不再铺路，脚下有支撑，可原路返回，自然地面无缺口。

### AC-6 主动开门进入房间 ← C-6
- 触发：分别用键盘E、触屏开门按钮进入和离开数据工厂。
- Given：新访问时两门关闭，无阅读面板，图形正常。
- When：靠近、停留、开门，在开门中输入方向和切语言，完成后再次输入方向；随后开出口并返回。
- Then：只有近处有门旁提示，不自动开启；开门动画约0.7秒，位置不变、旧输入不续走，双语不重置进度；新方向输入后可进入或离开，两扇门保持打开，重入/阅读冲突被忽略。图形故障中断时双语完整资料仍可用。

### AC-7 环境动态与光影 ← C-7
- Given：实际进入房间和海岸，未暂停。
- When：观察流水线至少一个循环，海岸观察流星和灯塔完整旋转，再启用减少动态。
- Then：物料、滚轮/机械臂、流星、光束与反光真实变化，人物和信息不被遮挡；水面无大块矩形建筑阴影，光束无硬三角边；减少动态时不继续自动运动。

### AC-8 超宽屏范围 ← C-8
- Given：进入真实主页并到达门前。
- When：在3440×1440、5120×1440调整窗口。
- Then：游玩画面居中且宽高比不超过2.4，门提示/顶部/底部操作均在画面内，无横向滚动、模型裸露尽头或资料重置。

### AC-10 星海层次与门墙接合 ← C-10
- Given：三视口与超宽屏均能访问项目星星、海岸和门口。
- When：观察星体光晕、水面运动与房屋墙角，核对真实投影和几何接合。
- Then：光晕完整位于海平线之上，远端无裸露地面色带；波峰向岸边移动；墙角不透出背景，门与侧墙形成完整门洞。

### AC-11 灯塔题记 ← C-11
- Given：主人公走到旅程尽头。
- When：分别使用两种主页语言，在桌面/手机查看题记，再向左返回。
- Then：题记横屏在灯塔右侧、竖屏在左侧，左上角标题不消失；换装按钮与题记同时出现，返回后同时收起，两者无标题/按钮遮挡，不自动打开阅读窗口。

### AC-9 首次切换准备 ← C-9
- Given：新加载主页，图形准备完成后从起点真实行走。
- When：首次进入和离开房间，各采样包含跨区的连续3秒帧间隔，并执行刷新、图形失败阅读。
- Then：本地受控桌面不出现超过250ms的首次绘制停顿，不剔除慢帧；加载、刷新和故障没有已释放材质回调报错，资料始终可读。记录设备、实际数据与限制，不声称手机真机或M3性能验收通过。

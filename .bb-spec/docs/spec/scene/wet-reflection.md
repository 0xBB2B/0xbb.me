# 湿地面倒影

## 目的
让雨夜地面的倒影既真实又稳定：灯光在湿路面上拉出竖直光带，俯视时淡、镜头压低时强；无论镜头怎么转，倒影都在正确的位置，不会突然出现或消失。

## 逻辑
- 地面倒影由两部分组成，不再每帧从地面下方把整个场景重新拍一遍：
  - **光带**：地面上一道竖直、模糊的亮条，代表某个灯在湿地面上的倒影。
  - **水洼环境倒影**：页面加载时从场景中央往四周拍一次全景图（环境图），水洼里按视线方向从这张图上取颜色。
- 会留下光带的灯，共三组：
  - 店铺招牌与店内灯：便利店店头招牌、正面玻璃窗、侧面玻璃窗、喫茶店门面、喫茶店灯箱、两台自动贩卖机。
  - 路灯与立式招牌：3 盏路灯、路边的 OxBB MART 立式招牌。
  - 信号灯与行人灯：光带颜色等于该灯此刻亮着的颜色（绿、黄、红）；灯灭时光带消失，行人灯闪烁时光带跟着闪。
- 光带的位置：把灯按它所在的地面做镜像，得到地面下方的镜像点；相机与镜像点的连线和地面的交点，就是光带的落点。光带从落点沿地面朝相机的方向拉长。
- 光带的强度随视角变化。记视线与地面法线（竖直向上）的夹角为 θ，反射比例 F(θ) = 0.04 + 0.96 × (1 − cos θ)^5（描述水面反射的常用近似公式）。光带中心亮度 = 灯的颜色 × F(θ) × 3。
  - 乘 3 是因为真实夜景里灯光比周围亮几十倍，画面亮度上限是 1，不放大就看不见。
  - 按此计算，亮度为 1 的灯在默认视角（θ 约 65°）下光带约 0.3，俯视（θ = 10°）约 0.12，贴地看（θ = 80°）约 1.2。
- 光带只画在和灯同一层的湿地面上：路面上的灯（路灯、信号灯）只在路面上留光带，停车场和人行道上的灯只在停车场和人行道上留光带；超出底座范围的部分不画。
- 水洼内：环境图倒影的比例取 F(θ) 与 0.25 中较大的一个，所以俯视时也看得到；光带经过水洼时亮度翻倍。
- 物体下方暗区：保时捷、两台自动贩卖机、垃圾分类桶、每辆自行车的正下方各有一块边缘柔和的暗区，画在光带和水洼倒影之上。从中心到一半半径处完全遮住倒影，再往外平滑渐变消失，看不出一圈圈台阶。
- 高档和低档画质下，地面倒影完全相同。

## 约束
- 场景中没有任何每帧重新渲染场景的镜面物体；环境图只在加载时拍一次。
- 光带落点严格按"相机—镜像点连线与地面的交点"计算，误差不超过 1 厘米。
- 光带中心亮度 = 灯颜色 × F(θ) × 3；F(θ) 在 θ 从 10° 增大到 80° 时单调增大，F(10°) ≤ 0.05，F(80°) ≥ 0.40。
- 信号灯和行人灯的光带颜色每帧跟随该灯当前颜色；灯灭时光带亮度为 0。
- 路面层的光带不画在停车场和人行道上，停车场层的光带不画在路面上。
- 水洼内环境倒影比例不低于 0.25；光带在水洼内亮度为水洼外的 2 倍。
- 每个列出的物体下方都有一块暗区：中心在物体底面投影范围内，离地面不超过 3 厘米，绘制顺序在光带和水洼倒影之后；半径一半以内不透明度不低于 0.9，贴图按线性插值采样。
- 静止镜头下倒影不随时间闪动（信号灯、行人灯本身的变化除外），不出现规则的重影条纹或摩尔纹。

## 例子
访客从默认视角看路口：信号灯绿灯亮着，路面上有一道淡绿色光带；店铺招牌和玻璃窗在停车场上映出几道暖白色光带；保时捷正下方是一块暗色区域。20 秒后信号灯变红，路面上的光带随之变成红色。

访客按住鼠标大幅度拖动一圈：光带始终跟着视角滑动到新的落点，压低镜头时变长变亮，抬高镜头时变短变淡，任何角度都不会整片消失。水洼里能看到模糊的楼房和灯光。

## 验收
- [ ] 场景里没有 three 的 Reflector 物体；加载后环境图只渲染一次，之后每帧的渲染次数与没有倒影时相同。
- [ ] 给定相机位置、灯的位置和地面高度，光带落点等于"相机—镜像点连线与地面的交点"，误差 ≤ 1 厘米。
- [ ] F(10°) ≤ 0.05，F(80°) ≥ 0.40，θ 在 10° 到 80° 之间时 F 单调增大；光带中心亮度 = 灯颜色 × F × 3。
- [ ] 三组灯都有对应的光带：店铺类 7 个（店头招牌、正面玻璃窗、侧面玻璃窗、喫茶店门面、喫茶店灯箱、两台自动贩卖机）、3 盏路灯、1 块立式招牌、每个车辆信号灯与行人灯。
- [ ] 信号灯从绿变红后，对应光带颜色在下一帧变为红色；灯灭时光带亮度为 0。
- [ ] 路面层光带在停车场区域不绘制，停车场层光带在路面区域不绘制。
- [ ] 保时捷、两台自动贩卖机、垃圾分类桶、每辆自行车下方各能找到一块暗区，满足位置、高度、绘制顺序和不透明度要求。
- [ ] 高档和低档画质下，地面倒影相关的物体和材质完全相同。

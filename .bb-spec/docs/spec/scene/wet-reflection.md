# 湿地面倒影

## 目的
让雨夜地面的倒影接近真实：俯视时淡、镜头压低时强；湿路面上只有灯光留下拉长的光带；物体正下方没有倒影。

## 逻辑
- 倒影出现在路面、停车场和人行道的湿地面上，高档和低档画质都显示（低档的倒影更模糊）。
- 反射强度随视角变化。记视线与地面法线（竖直向上）的夹角为 θ，倒影在画面上所占的比例为 F(θ) = 0.04 + 0.96 × (1 − cos θ)^5。
  - 这是描述水面反射的常用近似公式（Schlick 近似），0.04 是正对水面看时的反射率。
  - 按这个公式：从正上方往下看（θ = 10°）约 4%；默认镜头的视角（θ 约 65°）下约 10%；视线几乎贴着地面（θ = 80°）约 41%。
- 水洼以外的湿路面只映出亮处：
  - 倒影在这里的强度 = 倒影颜色 × F(θ) × 光带增益 g。
  - g 由倒影亮度 L（0 到 1）决定：L ≤ 0.35 时 g = 0（暗处不留倒影）；L 从 0.35 到 1 时 g 从 0 平滑增大到 3。
  - 之所以要乘 g：真实夜景里灯光比周围亮几十倍，比例很小的倒影也很醒目；画面亮度上限是 1，不放大就看不见。按此计算，亮度为 1 的招牌倒影在默认视角下约 0.3，俯视时约 0.12，贴地看时约 1.2。
  - 倒影只沿竖直方向模糊，拉成光带，不在水平方向随机扭动。
  - 先对倒影上每个取样点按它自己的亮度算 g，再把这些取样沿竖直方向平均成光带；不能先平均再算 g，否则小而亮的灯会和周围暗处平均掉，光带消失。
- 水洼内：倒影接近清晰的镜面，底下的路面标线仍隐约可见；倒影比例取 F(θ) 与 0.25 中较大的一个，所以俯视时水洼里也看得到倒影。
- 物体下方暗区：保时捷、两台自动贩卖机、垃圾分类桶、每辆自行车的正下方各有一块边缘柔和的暗区。暗区画在倒影之上，从中心到一半半径处完全遮住倒影，再往外平滑渐变消失，渐变里看不出一圈圈台阶。

## 约束
- 湿路面上倒影所占比例严格按 F(θ) 计算；θ 从 10° 增大到 80° 时比例单调增大。
- 水洼以外的湿路面上，倒影强度按「倒影颜色 × F(θ) × g(L)」计算；g(L) 在 L ≤ 0.35 时为 0，L = 1 时为 3，其间单调增大。
- 水洼以外的湿路面倒影在水平方向不做随机偏移。
- 水洼内倒影比例不低于 0.25。
- 上面列出的每个物体下方都有一块暗区：暗区中心在物体底面投影范围内，离地面不超过 3 厘米，绘制顺序在地面倒影之后；半径一半以内不透明度不低于 0.9，贴图按线性插值采样。
- 静止镜头下倒影不随时间闪动，不出现规则的重影条纹或摩尔纹。
- 高档和低档画质下，以上规则都成立。

## 例子
访客从默认视角看停车场：地面只有招牌、店内灯光和信号灯留下的几道淡淡竖直光带，暗处的路面几乎没有倒影；保时捷正下方是一块暗色区域，看不到车身倒影。

访客把镜头压低到接近平视：同一片地面上的光带明显变亮，水洼里能清楚看到招牌的倒影。倒影随镜头移动连续变强变弱，不会突然整片出现或消失。

## 验收
- [ ] F(10°) ≤ 0.05，F(80°) ≥ 0.40，θ 在 10° 到 80° 之间时 F 单调增大。
- [ ] g(0.3) = 0，g(0.35) = 0，g(1) = 3，L 在 0.35 到 1 之间时 g 单调增大。
- [ ] 水洼内倒影比例在 θ = 10° 时不低于 0.25。
- [ ] 保时捷、两台自动贩卖机、垃圾分类桶、每辆自行车下方各能找到一块暗区，满足位置、高度、绘制顺序和不透明度要求。
- [ ] 高档和低档画质下，地面倒影都可见。

# 旧楼外观

## 目的
让便利店左侧的旧楼像一栋真实的昭和年代两层店铺住宅：一楼是夜里已经打烊的喫茶店，二楼住人，屋顶有常见的杂物。

## 逻辑
- 旧楼是隔着小巷、位于便利店左侧的两层楼，正面朝主路。
- 外墙四面都有材质：
  - 一楼（离底座地面约 3.5 米以下）是暖褐色小口瓷砖，能看出一块块瓷砖和砖缝。
  - 二楼是灰白色水泥抹面，墙上有从上往下的深色雨水流痕。
  - 一楼和二楼之间有一道横向分隔线，四面连续。
- 外墙附属物：
  - 一根雨水管，从屋顶边沿竖直通到地面。
  - 一楼侧墙上有一个电表箱。
- 一楼喫茶店（正面）：
  - 正面左边是大玻璃窗，右边是木框玻璃门，没有卷帘门。
  - 店已经打烊：店里的灯全灭，玻璃很暗，只隐约看得到画在贴图上的吧台、高脚凳和吊灯的轮廓。
  - 玻璃门上挂着一块写着「準備中」的小牌。
  - 门上方有「喫茶フブキ」招牌和红色雨棚。
  - 菜单黑板和灯箱已经收进店里，门口人行道上没有这两样东西。
  - 喫茶店没有光源。
- 二楼：
  - 正面两扇窗、侧面两扇窗都挂着窗帘，窗帘画在窗户贴图上；窗帘底色是中性近白色，窗户呈现的颜色由灯光决定。
  - 各扇窗的灯光：正面一扇暖光、一扇暗；侧面一扇白光、一扇电视光（忽明忽暗）。
  - 一楼侧面（朝小巷）另有一扇挂窗帘的暗窗。
  - 阳台上有一根晾衣杆，挂着 3 到 4 个空衣架，不挂衣服。
  - 晾衣杆两端各有一根立在阳台地面上的托架立柱；衣架是三角形加挂钩，挂钩套在杆上。
  - 阳台上有 2 到 3 盆盆栽和一台空调外机。
- 屋顶：
  - 四周围一圈女儿墙。
  - 有一间带门的楼梯间小屋。
  - 有一个晾衣架。
  - 有一个水箱和一根天线。

## 约束
- 旧楼的全部物件都放在场景名为 `neighbor-building` 的组里。
- `neighbor-building` 组内的可绘制物件总数不超过 72 个。
- 旧楼的实体物件都带深蓝色细描边，和场景其他物件一致。
- 一楼墙面和二楼墙面使用不同的贴图；分隔线高度在离地 3.2 到 3.8 米之间。
- 喫茶店的玻璃门和玻璃窗不发光：仍带着画有店内的贴图，材质颜色的红、绿、蓝三个分量都不超过 0.08（颜色是线性值，0.08 在屏幕上约为三成亮度），没有自发光（自发光颜色为黑色或没有自发光）。
- 「準備中」牌挂在玻璃门外侧（整块牌子在玻璃面前方）：牌子中心的水平位置落在门框左右范围内，离底座地面 1.2 到 1.9 米，牌面文字是「準備中」。
- 招牌文字是「喫茶フブキ」。
- 喫茶店门外的人行道上没有菜单黑板和灯箱。
- 喫茶店正面没有卷帘门。
- 旧楼不包含任何点光源、聚光灯。
- 晾衣杆上挂 3 到 4 个衣架，衣架上没有衣服类物件。
- 高档和低档画质下，旧楼显示的物件完全相同。

## 例子
访客从默认视角转到旧楼正面：
- 一楼是暖褐色瓷砖墙，「喫茶フブキ」已经打烊：玻璃门窗暗着，隐约能看出里面的吧台和吊灯，玻璃门上挂着「準備中」小牌。
- 门口人行道上空着，没有菜单黑板和灯箱。
- 二楼是灰白抹面墙，窗户挂着窗帘，阳台的晾衣杆上挂着 3 个空衣架，旁边是两盆盆栽和空调外机。
- 屋顶围着女儿墙，楼梯间小屋旁边立着晾衣架和水箱。

在手机上用低档画质打开，看到的旧楼物件和桌面一样。

## 验收
- [ ] 场景中有 `neighbor-building` 组，组内可绘制物件数量不超过 72。
- [ ] 一楼墙面与二楼墙面使用两张不同的贴图；分隔线高度在离地 3.2 到 3.8 米之间。
- [ ] 能找到雨水管（竖直，从屋顶边沿到地面）、电表箱、阳台空调外机。
- [ ] 喫茶店玻璃门和玻璃窗带店内贴图，材质颜色三个分量都不超过 0.08，且没有自发光。
- [ ] 能找到「準備中」牌：整块在玻璃面前方，中心水平位置在玻璃门左右范围内，离地 1.2 到 1.9 米，牌面文字为「準備中」。
- [ ] 招牌文字为「喫茶フブキ」。
- [ ] 喫茶店正面找不到卷帘门物件。
- [ ] `neighbor-building` 组内没有任何光源对象。
- [ ] 场景中找不到菜单黑板和灯箱。
- [ ] 晾衣杆上有 3 到 4 个衣架，没有衣服物件；阳台上有 2 到 3 盆盆栽。
- [ ] 晾衣杆两端各有一个托架；每个衣架的挂钩与晾衣杆的包围盒相交。
- [ ] 二楼四扇窗与一楼侧面暗窗的窗面都挂窗帘贴图；二楼窗面颜色依次为暖光、暗、白光、电视光，一楼侧面窗为暗。
- [ ] 屋顶能找到女儿墙、带门的楼梯间小屋、晾衣架、水箱和天线。
- [ ] 旧楼实体物件的材质都没有关闭描边（玻璃门窗等贴图面除外）。
- [ ] 切换到低档画质后，`neighbor-building` 组内可见物件数量与高档相同。

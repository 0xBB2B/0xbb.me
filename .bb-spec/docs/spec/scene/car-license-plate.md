# 保时捷的日本车牌

## 目的
规定保时捷车头和车尾的车牌写什么、长什么样、贴在哪。

## 逻辑
- 保时捷车头、车尾各有一块车牌，两块内容相同。
- 样式是日本普通自家用车牌：白底、绿字、不发光。
- 文字分两排：
  - 上排：地名「秋葉原」（日文写法）和分类号「310」。
  - 下排：左边是平假名「み」，右边是号码「・9 92」。号码 992 是三位数，按日本车牌的写法在前面补一个圆点，百位和后两位之间留一个空。
- 尺寸按真车比例：宽 33 厘米、高 16.5 厘米（宽高比 2:1）。车牌是车的一部分，跟着整车等比缩到 90%，所以场景里实际约宽 29.7 厘米、高 14.9 厘米。
- 车牌是一块贴在车身表面的薄板，字画在贴图上，不加载外部图片或模型文件。
- 位置：
  - 车尾：左右居中，在贯穿式尾灯下方、排气管上方，贴在深红色的车牌凹槽底板上。
  - 车头：左右居中，在前保险杠上、进气口上方；车牌上沿不高于前大灯下沿。
  - 两块车牌的中心离停车场地面都约 45 厘米。
- 车牌的字用场景里招牌已经在用的字体，不新增字体文件。

## 约束
- 车牌正好 2 块，一块在车头、一块在车尾。
- 每块在场景里的实际尺寸为宽 29.7 厘米、高 14.9 厘米，误差不超过 1 厘米。
- 两块都左右居中：车牌中心偏离车身中轴线不超过 1 厘米。
- 车牌中心离停车场地面 40 到 50 厘米。
- 车尾车牌整块低于贯穿式尾灯的下沿、高于排气管的上沿。
- 车头车牌整块高于进气口的上沿，车牌上沿不高于前大灯的下沿。
- 车牌贴着车身：在车牌中心处，背面离它正后方的车上部件表面不超过 3 厘米；从车头或车尾正对着看，车牌不被车身或其他部件挡住。
- 车牌不发光：材质颜色的亮度低于泛光阈值，不产生光晕；加车牌前后场景里灯的数量相同。
- 贴图上画的文字正好是「秋葉原」「310」「み」「・9 92」这四段；底色是白色，字是绿色；除底色和文字外不画边框线。
- 车牌上的每个字都在画布贴图的字体预载文字里，预载文字里没有贴图不会用到的字。

## 例子
访客把镜头转到保时捷车头前方：前保险杠正中有一块白底绿字的车牌，上排写「秋葉原 310」，下排写「み ・9 92」，车牌在进气口上方、大灯下方。绕到车尾：贯穿式尾灯下面正中是同样的一块车牌。双闪闪烁时车牌不跟着发亮。

## 验收
- [ ] 保时捷上有且只有 2 块车牌，一块中心在车身中心前方（车头一侧），一块在后方（车尾一侧）。
- [ ] 每块车牌的世界尺寸为宽 29.7 厘米、高 14.9 厘米，误差不超过 1 厘米。
- [ ] 每块车牌的中心在车宽方向上偏离车身中轴线不超过 1 厘米。
- [ ] 每块车牌的中心离停车场地面 40 到 50 厘米。
- [ ] 车尾车牌的最高点低于贯穿式尾灯的最低点，最低点高于排气管的最高点。
- [ ] 车头车牌的最低点高于进气口的最高点，最高点不高于前大灯灯罩的最低点。
- [ ] 在每块车牌的中心处，背面离它正后方的车上部件表面不超过 3 厘米；从车牌正前方（车头车牌朝车头方向、车尾车牌朝车尾方向）朝车牌中心和四角看，先碰到的都是车牌。
- [ ] 车牌材质不发光、颜色亮度低于泛光阈值；场景里灯的数量与加车牌前相同。
- [ ] 车牌贴图上画出的文字是「秋葉原」「310」「み」「・9 92」；贴图底色为白色，文字颜色为绿色；贴图上没有描边（不画边框线）。
- [ ] 车牌贴图上画出的每个字都在字体预载文字里；字体预载文字里没有任何贴图都不画的字。

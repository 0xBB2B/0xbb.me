# 环境动效

## 目的
让静态的微缩模型保持「雨夜里仍在运转」的生命感，每种动效的节奏固定、可测。

## 逻辑
整体视角下以下动效持续循环；进入资料视角、小票贴好后，所有动效随三维画面一起停在当前画面，退出资料视角后从停下的地方接着播放：

| 动效 | 规则 |
|---|---|
| 降雨 | 雨丝只在底座正上方的空间内生成和下落；落到屋顶、雨棚、地面等表面即消失；离镜头越远越淡；雨丝基准数量 3900 条（实际数量按画质档位取比例） |
| 屋檐滴水 | 雨棚前沿有水滴依次挂住、下落，落地前消失 |
| 水洼 | 地面散布若干边缘清晰的小水洼，水洼内倒影接近镜面，底下的路面标线仍隐约可见；每台设备上水洼的位置、大小都相同 |
| 水洼波纹 | 雨点在水洼内荡开同心圆波纹；水洼以外的路面不出现波纹 |
| 屋顶积水 | 便利店屋顶和旧楼屋顶上各有 2 到 4 块位置固定、边缘清晰、轮廓不规则的小积水（边缘像路面水洼那样凹凸不平，不是圆或椭圆），积水面泛着一层淡淡的水光，雨点在积水里荡开同心圆波纹；积水以外的屋顶面不出现水光和波纹；每台设备上积水的位置、大小、轮廓都相同；高档和低档画质都显示 |
| 落地水花 | 雨点落到地面或屋顶处短暂出现一个小水花，随即消失；屋顶上的水花出现在屋顶表面上方，不被屋顶板挡住 |
| 湿路面倒影 | 水洼以外的湿路面上，灯光倒影拉成竖直光带；倒影的模糊是平滑过渡的，不出现颗粒噪点（摩尔纹），也不出现一格一格的重影条纹，不逐帧闪烁 |
| 玻璃雨痕 | 便利店玻璃外侧有水滴沿玻璃下滑 |
| 招牌闪烁 | 店头招牌每隔 4 到 9 秒随机闪烁一次，每次持续 0.25 到 0.6 秒 |
| 自动门 | 每隔 6 到 11 秒自动打开，保持打开 2.6 秒后关上 |
| 双闪 | 保时捷四角琥珀色转向灯以 0.9 秒为周期闪烁（亮 0.45 秒、灭 0.45 秒），闪亮时四个车角外侧的地面各泛起一小片琥珀色光斑（光源在四个角，不在车头车尾正中）；光斑只落在车位所在的停车场地面上，不越过路沿照到人行道或马路 |
| 车辆信号灯 | 20 秒一个周期：绿灯 8 秒、黄灯 2 秒、红灯 10 秒 |
| 行人信号灯 | 与车辆信号灯联动；变红前绿灯闪烁 1 到 2 秒 |
| 其他 | 旧楼一扇窗透出忽明忽暗的电视光；店门口的「おでん」旗子轻微摆动 |

## 约束
- 雨丝不出现在底座正上方空间以外。
- 雨丝基准数量为 3900 条，落地水花最多 1100 个。
- 波纹只出现在水洼范围内。
- 地面水洼的分布由整数随机函数决定，不用 sin 这类结果随显卡精度变化的函数，所以每台设备上水洼的位置、大小都相同。随机函数的算法：
  1. 把取样点坐标向下取整，得到格坐标 (ix, iy)；
  2. 令 a = ix + 4104，b = iy + 4152；
  3. n = ((a × 1597334673) 异或 (b × 3812015801)) × 1597334673，所有乘法都按 32 位无符号整数计算，超出 32 位的部分直接丢掉；
  4. 随机值 = n ÷ 4294967296，范围 0 到 1。
- 只换随机函数，水洼的噪声叠加方式和判定阈值不变。按这个函数算，在底座中央 24×24 米范围（x、z 都在 -12 到 12 米）内，水洼约占 15.7%（车道上约 18.5%，人行道和停车场上约 13.5%）。
- 屋顶波纹和水光只出现在屋顶积水范围内，且只画在两个屋顶的顶面范围内；高档和低档画质下都显示。
- 每块积水有一个写死的外圈：一个椭圆，数据是中心位置和两个方向的半径。每个屋顶有 2 到 4 块，每块外圈面积不超过 2 平方米；外圈完整落在女儿墙以内，不压在屋顶设备（空调、水箱、天线、楼梯间等）底下。
- 积水的实际轮廓由外圈往里收出来：每个位置收多少，由该位置的世界坐标经过与地面水洼相同的整数随机函数算出的噪声决定，不随时间变化。轮廓只往里收、不超出外圈，所以积水仍在女儿墙以内、不压屋顶设备；每台设备上轮廓相同。
- 轮廓的算法（p 是屋顶上一点的世界坐标 (x, z)，c 是外圈中心，rx、rz 是外圈两个方向的半径）：
  1. 平滑噪声 vnoise(q)：取 q 所在格子四个角的随机值（用上面的整数随机函数），按 q 在格内的小数部分 f 做双线性插值，插值权重用 f×f×(3−2f)；
  2. 收缩系数 k(p) = 1 − 0.42 × (vnoise(p×2.3)×0.65 + vnoise(p×5.7)×0.35)，范围 0.58 到 1；
  3. 归一化距离 d(p) = ((x−c.x)/rx, (z−c.z)/rz) 的长度；d(p) < k(p) 的点在积水内。
- 轮廓要看得出不规则：沿外圈一周，轮廓到中心的距离与外圈半径之比，最大值和最小值至少相差 0.15；这个比值最小不低于 0.5，积水不会缩成一个小点。
- 落在屋顶范围内的雨丝和水花，其落点高度等于该屋顶顶面高度（误差不超过 3 厘米）。
- 双闪周期为 0.9 秒，亮灭各占一半。
- 双闪照地的点光源共 4 盏，分别位于车身四角外侧（左前、右前、左后、右后），不在车身中轴线上。
- 每盏双闪点光源在地面上的照亮半径（水平方向）不超过 1 米，且小于它到最近路沿内侧的水平距离。
- 车辆信号灯周期为 20 秒，绿、黄、红时长依次为 8、2、10 秒。
- 自动门两次打开的间隔在 6 到 11 秒之间，每次打开持续 2.6 秒。
- 湿路面倒影不出现规则的重影条纹，也不出现颗粒噪点（摩尔纹）；做法是先把倒影图缩小成多级副本（mipmap，每级把上一级相邻像素平均），光带拉得越长就从越小的副本取样，取样位置不加逐像素的随机错开。静止镜头下倒影不随时间闪动。
- 系统的「减少动态效果」设置不改变以上任何动效。

## 例子
访客把镜头转到底座侧面平视：
- 雨丝只落在底座上方，底座外侧的背景里没有雨。
- 保时捷双闪每 0.9 秒亮一次，亮的瞬间车旁地面泛起琥珀色光。
- 路口信号灯绿了 8 秒后变黄，2 秒后变红。

访客把镜头转到旧楼屋顶上方往下看：屋顶上有几块小积水，雨点在积水里荡开同心圆波纹；积水外的屋顶面上不断冒出一闪即逝的小水花。用手机（低档画质）看同一个位置，积水波纹同样可见。

访客在系统里开启「减少动态效果」后刷新页面，雨和双闪照常播放。

同一个访客先用 Mac 笔记本、再用装 NVIDIA 显卡的 Windows 台式机打开页面：两台电脑上，斑马线旁和停车场里的水洼出现在同样的位置，形状也一样。

## 验收
- [ ] 雨丝的水平坐标全部落在底座范围内。
- [ ] 默认创建的雨丝为 3900 条，落地水花为 1100 个。
- [ ] 双闪亮灭时长各为 0.45 秒。
- [ ] 双闪点光源 4 盏，各自离车身中轴线（车宽方向）不少于 0.7 米，前后各两盏。
- [ ] 每盏双闪点光源都设置了照射距离上限；按该上限和光源离地高度算出的地面照亮半径 ≤ 1 米，且小于光源到最近路沿内侧的水平距离。
- [ ] 车辆信号灯一个周期为 20 秒，绿 8 秒、黄 2 秒、红 10 秒。
- [ ] 自动门打开间隔在 6 到 11 秒之间，每次打开 2.6 秒。
- [ ] 水洼以外的路面不绘制波纹。
- [ ] 地面倒影层和地面波纹层的着色器里，水洼用的随机函数不含 sin，只用整数乘法和异或。
- [ ] 用上面的算法在 JS 里逐格算出的水洼分布，与浏览器里着色器实际算出的水洼分布，逐像素比对一致率不低于 99%。
- [ ] 在底座中央 24×24 米范围内，水洼占 15.7%，误差不超过 1 个百分点。
- [ ] 湿路面倒影的取样不含逐像素随机错开；倒影图带多级缩小副本，改变窗口大小后仍然带；光带越长，取样用的副本越小（水洼里光带最短，用原图取样，保持镜面清晰）。
- [ ] 便利店屋顶和旧楼屋顶各有一个积水层，范围不超出对应屋顶的顶面；切换到低档画质后仍然可见。
- [ ] 每个屋顶的积水数据有 2 到 4 块，每块面积不超过 2 平方米，都在女儿墙以内，与屋顶设备的水平投影不重叠。
- [ ] 积水层使用的积水位置与积水数据一致；积水层除波纹外还画出一层非零亮度的水光。
- [ ] 积水层着色器算轮廓时用到与地面水洼相同的整数随机函数，不含 sin；决定轮廓的噪声只用世界坐标取样，不含时间。
- [ ] 按着色器的同一算法在 JS 里算每块积水的轮廓：沿外圈一周取 72 个方向，轮廓半径与外圈半径之比都在 0.5 到 1 之间，最大值减最小值不小于 0.15。
- [ ] 落点在两个屋顶范围内的雨丝与水花，落点高度与对应屋顶板顶面高度相差不超过 3 厘米。
- [ ] 开启「减少动态效果」时以上动效照常运行。

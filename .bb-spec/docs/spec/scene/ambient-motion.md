# 环境动效

## 目的
让静态的微缩模型保持「雨夜里仍在运转」的生命感，每种动效的节奏固定、可测。

## 逻辑
页面打开后以下动效持续循环，整体视角和资料视角下都不暂停：

| 动效 | 规则 |
|---|---|
| 降雨 | 雨丝只在底座正上方的空间内生成和下落；落到屋顶、雨棚、地面等表面即消失；离镜头越远越淡 |
| 屋檐滴水 | 雨棚前沿有水滴依次挂住、下落，落地前消失 |
| 水洼 | 地面散布若干边缘清晰的小水洼，水洼内倒影接近镜面，底下的路面标线仍隐约可见 |
| 水洼波纹 | 雨点在水洼内荡开同心圆波纹；水洼以外的路面不出现波纹 |
| 落地水花 | 雨点落地处短暂出现一个小水花，随即消失 |
| 湿路面倒影 | 水洼以外的湿路面上，灯光倒影拉成竖直光带 |
| 玻璃雨痕 | 便利店玻璃外侧有水滴沿玻璃下滑 |
| 招牌闪烁 | 店头招牌每隔 4 到 9 秒随机闪烁一次，每次持续 0.25 到 0.6 秒 |
| 自动门 | 每隔 6 到 11 秒自动打开，保持打开 2.6 秒后关上 |
| 双闪 | 保时捷四角琥珀色转向灯以 0.9 秒为周期闪烁（亮 0.45 秒、灭 0.45 秒），闪亮时照亮周围地面 |
| 车辆信号灯 | 20 秒一个周期：绿灯 8 秒、黄灯 2 秒、红灯 10 秒 |
| 行人信号灯 | 与车辆信号灯联动；变红前绿灯闪烁 1 到 2 秒 |
| 其他 | 旧楼一扇窗透出忽明忽暗的电视光；店门口的「おでん」旗子轻微摆动 |

## 约束
- 雨丝不出现在底座正上方空间以外。
- 波纹只出现在水洼范围内。
- 双闪周期为 0.9 秒，亮灭各占一半。
- 车辆信号灯周期为 20 秒，绿、黄、红时长依次为 8、2、10 秒。
- 自动门两次打开的间隔在 6 到 11 秒之间，每次打开持续 2.6 秒。
- 系统的「减少动态效果」设置不改变以上任何动效。

## 例子
访客把镜头转到底座侧面平视：
- 雨丝只落在底座上方，底座外侧的背景里没有雨。
- 保时捷双闪每 0.9 秒亮一次，亮的瞬间车旁地面泛起琥珀色光。
- 路口信号灯绿了 8 秒后变黄，2 秒后变红。

访客在系统里开启「减少动态效果」后刷新页面，雨和双闪照常播放。

## 验收
- [ ] 雨丝的水平坐标全部落在底座范围内。
- [ ] 双闪亮灭时长各为 0.45 秒。
- [ ] 车辆信号灯一个周期为 20 秒，绿 8 秒、黄 2 秒、红 10 秒。
- [ ] 自动门打开间隔在 6 到 11 秒之间，每次打开 2.6 秒。
- [ ] 水洼以外的路面不绘制波纹。
- [ ] 开启「减少动态效果」时以上动效照常运行。

# 整体模型构成与整体视角

## 目的
规定首页唯一的三维画面：一个放在展示台上的雨夜日式便利店街角微缩模型，以及访客在整体视角下怎么观察它。

## 逻辑
- 页面只有一个画面：整个微缩模型悬浮在深蓝渐变背景中，没有其他页面或路由。
- 模型建在边长 26 米的正方形底座上，底座放在更大一圈的黑色亮面展示台上，展示台和底座之间有黄铜装饰线；展示台正面嵌铭牌。
- 底座上的街区布局：
  - 便利店在中间偏后，门脸朝向主路，屋顶有招牌灯箱、空调外机，前方有雨棚。
  - 店前是停车场，3 个车位。
  - 店内透过正面和侧面大玻璃可见：货架、饮料柜、便当饭团柜、冰柜、收银台、烟草架、咖啡机、关东煮、杂志架、地面导视。
  - 主路沿底座前沿横穿；小路从主路垂直伸向底座后方，两者成丁字路口。路口有两条斑马线，主路中线为黄色实线。
  - 小路靠路口的车道上喷有「止まれ」字样和停车线，路口立倒三角「止まれ」标志；小路不设车辆信号灯。
  - 倒三角标志牌面正对小路上驶向路口的车辆（不偏转），牌子轮廓就是倒三角，三角形以外不露出黑色或灰色的矩形底板。
  - 左侧有两层旧楼和一条小巷；小巷出口对着停车场，不是公路，不设「止まれ」路面字和标志。
  - 街道设施：立式招牌、路灯、电线杆与电线、信号灯、护栏、绿篱、自动贩卖机、自行车、雨伞架、垃圾分类桶、公告栏、路口反光镜、排水沟格栅。
- 红色保时捷 911（992 代 Carrera，加装固定尾翼）停在店门前正中的车位上，车头朝向主路。车身用代码几何体拼出，不加载外部模型文件。
  - 车是熄火停放状态：前大灯不亮（灯罩只是浅色，不发光），只有双闪在闪；贯穿式尾灯保持微亮。
  - 所有车灯（前大灯灯罩、双闪、侧转向灯、贯穿式尾灯、高位刹车灯）都贴在车身表面上：朝向车身的背面离车身外表面不超过 2 厘米，不整块埋进车身（从车外能看到），向外凸出不超过 3 厘米。
  - 前大灯保持 992 标志性的大椭圆灯罩（俯视尺寸不小于约 24×20 厘米），不能压成细缝。
  - 前挡风玻璃、后窗玻璃和两侧车窗都顺着车身弧面贴合：玻璃任一点离车身外表面不超过 1 厘米（侧面看伸出车身轮廓不超过 1 厘米、与车身之间没有缝隙）；前挡风玻璃横向宽度不小于 0.9 米。
  - 车轮只有轮胎和一片素色轮圈，不加轮辐、轮毂盖、刹车卡钳等装饰；车身不压住轮胎外侧面。
  - 车的光影：
    - 车底暗影：车底下的地面上贴一块暗色贴片，让车看起来压在地上而不是浮着。贴片中间最暗，往四周渐渐变淡，到边缘完全透明；俯视时它盖住整个车身投影，每边比车身多出去不超过 0.3 米。四个轮胎正下方各再贴一块更深的小暗块，每块俯视不超过 0.6×0.4 米。暗影同时压暗地面和地面上的倒影，本身不发光、没有描边，也不会在倒影里再出现一次。
    - 车漆边缘光：便利店的灯在车背后，车漆朝便利店那一侧的轮廓边缘出现一道暖白色亮线，像被灯勾了边。亮线是硬边的一条（和卡通分层明暗一个风格），不是平滑渐变；车头那一侧（背对便利店）没有这道亮线。只有车漆有边缘光，车窗、轮胎、车灯和场景里其他物件都没有。
    - 尾灯照地：贯穿式尾灯在车尾后方（朝便利店一侧）的停车场地面上映出一片淡红色光晕，从车尾往后不超过 1 米，左右不超过车宽，不照到便利店门口。光晕是贴在地面上的发光贴片，不是新加的灯，所以不会把车身或便利店照红，也不产生泛光光晕。
- 画风：卡通分层着色，所有实体物件带深蓝色细描边，场景罩一层蓝色雾气，发光体有泛光光晕，湿地面有真实倒影。
- 整体视角的镜头：
  - 默认从右前上方俯视整个模型，展示台和铭牌完整入画。
  - 按住左键拖动旋转，滚轮或双指缩放，右键或双指拖动平移。
  - 镜头仰角被限制，无法转到底座下方。
  - 缩放距离下限 16 米，上限 80 米。
  - 镜头视场角：视口宽高比 ≥ 1.6 时竖直视场角为 28°；宽高比 < 1.6（竖屏、方屏、4:3 等）时加大竖直视场角，使水平视野等于宽高比 1.6、竖直 28° 时的水平视野。镜头距离与宽屏相同，不因屏幕变窄而拉远（拉远会被雾吞掉）。

## 约束
- 整体视角下，画面上不出现铭牌以外的任何文字界面、按钮或菜单；加载页和资料视角不受此限。
- 整体视角下页面不能滚动，滚轮只用于缩放镜头。
- 底座和展示台之外只有背景，不出现其他三维物件。
- 场景不开阴影（不做实时阴影计算）；车底暗影是贴在地面上的贴片，不算开阴影。便利店屋顶和外墙只被照向它们正面的灯照亮，位于它们背后的灯（比如店内的顶灯）不给它们增加亮度，所以屋顶和外墙上不会出现一圈圈的光斑。
- 小路没有车辆信号灯；主路路口有信号灯。
- 车头朝向主路（背对便利店）。
- 前大灯不发光；所有车灯与车身表面的距离不超过 2 厘米；车轮只有轮胎和轮圈。
- 车的光影效果（车底暗影、边缘光、尾灯照地）都不新增灯光，场景里的灯数量不变。
- 路沿、地块、人行道、便利店地板与外墙及门前底框等相邻物件的外表面不共面，画面上不出现相互抢显示的闪烁条纹或锯齿；路沿内侧与人行道砖面之间不露缝；路沿不伸出底座。
- 镜头无法转到底座下方，缩放距离限制在 16 到 80 米之间（任何视口都一样）。
- 宽高比 < 1.6 时，水平视野不小于宽高比 1.6、竖直视场角 28° 时的水平视野。

## 例子
访客首次打开页面，看到右前上方俯视的微缩街角：
- 招牌写着「0xBB MART」，透过玻璃能看到店里的饮料柜和收银台。
- 店门前停着一辆打着双闪的红色保时捷，车头对着马路。车底有一片暗影，车稳稳压在地上；车顶和车尾的轮廓被店里的灯勾出一道暖白亮边；车尾后面的湿地面泛着淡淡的红光。
- 右侧小路上喷着「止まれ」。
- 展示台正面有铭牌。

访客滚轮一直往外滚，镜头停在距离 80 米处，不会再远；往下拖到底，镜头停在略高于底座边缘的高度，看不到底座底面。

## 验收
- [ ] 首屏默认视角下，展示台和铭牌完整可见。
- [ ] 场景中能找到便利店、保时捷、主路、小路、两条斑马线、一处「止まれ」路面字（在小路上）、倒三角「止まれ」标志。
- [ ] 场景里只有一块「止まれ」标志、一处「止まれ」路面字，小巷出口没有。
- [ ] 倒三角标志牌面朝向与小路方向平行、正对驶向路口的车辆；牌面几何形状是三角形，没有矩形底板。
- [ ] 保时捷位于店门前的车位上，车头朝主路。
- [ ] 保时捷前挡风玻璃、后窗玻璃、两侧车窗的每个顶点离车身外表面不超过 1 厘米。
- [ ] 前挡风玻璃在车宽方向的跨度不小于 0.9 米。
- [ ] 保时捷前大灯材质不发光；前大灯灯罩、双闪、侧转向灯、尾灯、高位刹车灯的背面离车身外表面不超过 2 厘米、不被车身整块遮住、外凸不超过 3 厘米；前大灯灯罩俯视尺寸不小于约 24×20 厘米；每个车轮只有轮胎与轮圈两个部件。
- [ ] 车底暗影贴片盖住车身俯视投影，每边多出不超过 0.3 米；中心不透明度不低于 0.5，边缘为 0；四个轮胎正下方各有一块俯视不超过 0.6×0.4 米的更深暗块；暗影材质不发光、没有描边，只有正面朝上可见（从地面倒影的镜像视角看不到）。
- [ ] 车漆材质带边缘光：朝便利店方向、边缘处的车漆比朝主路方向的同角度车漆更亮，亮线颜色暖白；车漆以外的材质（车窗、轮胎、车灯、场景其他物件）都没有边缘光。
- [ ] 车尾后方地面有淡红色光晕贴片：从车尾往后不超过 1 米、左右不超过车宽，不到便利店门口；贴片颜色的亮度低于泛光阈值。
- [ ] 加入这些光影效果前后，场景里的灯（点光源、聚光灯、平行光、半球光）数量相同。
- [ ] 路沿外侧面与地块、人行道侧面不在同一平面上；路沿内侧与砖面间隙小于 2 毫米；路沿在底座范围（±13 米）内。
- [ ] 便利店地板的四个侧面，与同一高度范围内的外墙、门前金属底框的外表面都不在同一平面上；外墙与门前金属底框、顶梁这些金属件朝同一方向、并且在面上有重叠部分的表面也不在同一平面上（都相距至少 4 毫米）；只是边挨着边、面上不重叠的不算。
- [ ] 便利店屋顶和外墙的材质，对从背面照来的光（表面法线和指向灯的方向夹角大于 90°）亮度贡献为 0；场景里其他卡通材质的分层明暗不变。
- [ ] 小路方向没有车辆信号灯。
- [ ] 整体视角下，页面除铭牌外没有任何文字界面元素。
- [ ] 缩放距离被限制在 16 到 80 米之间；仰角限制使镜头无法低于底座。
- [ ] 390×844 视口下，默认视角的展示台与铭牌完整在画面内，镜头到观察目标的距离与 1440×900 相同。
- [ ] 390×844 视口下，竖直视场角约 82°，此时水平视野与宽高比 1.6、竖直 28° 时相同。
- [ ] 整体视角下滚动滚轮后 `scrollY` 仍为 0，镜头距离改变。

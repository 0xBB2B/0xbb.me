# 整体模型构成与整体视角

## 目的
规定首页唯一的三维画面：一个放在展示台上的雨夜日式便利店街角微缩模型，以及访客在整体视角下怎么观察它。

## 逻辑
- 页面只有一个画面：整个微缩模型悬浮在深蓝渐变背景中，没有其他页面或路由。
- 模型建在边长 26 米的正方形底座上，底座放在更大一圈的黑色亮面展示台上，展示台和底座之间有黄铜装饰线；展示台正面嵌铭牌。
- 底座上的街区布局：
  - 便利店在中间偏后，门脸朝向主路，屋顶有招牌灯箱、空调外机，前方有雨棚。
  - 店前是停车场，3 个车位。
  - 店内透过正面和侧面大玻璃可见：货架、饮料柜、便当饭团柜、冰柜、收银台、烟草架、咖啡机、关东煮、杂志架、地面导视。
  - 主路沿底座前沿横穿；小路从主路垂直伸向底座后方，两者成丁字路口。路口有两条斑马线，主路中线为黄色实线。
  - 小路靠路口的车道上喷有「止まれ」字样和停车线，路口立倒三角「止まれ」标志；小路不设车辆信号灯。
  - 左侧有两层旧楼和一条小巷，小巷出口地面也喷有「止まれ」。
  - 街道设施：立式招牌、路灯、电线杆与电线、信号灯、护栏、绿篱、自动贩卖机、自行车、雨伞架、垃圾分类桶、公告栏、路口反光镜、排水沟格栅。
- 红色保时捷 911（992 代 Carrera，加装固定尾翼）停在店门前正中的车位上，车头朝向主路。车身用代码几何体拼出，不加载外部模型文件。
- 画风：卡通分层着色，所有实体物件带深蓝色细描边，场景罩一层蓝色雾气，发光体有泛光光晕，湿地面有真实倒影。
- 整体视角的镜头：
  - 默认从右前上方俯视整个模型，展示台和铭牌完整入画。
  - 按住左键拖动旋转，滚轮或双指缩放，右键或双指拖动平移。
  - 镜头仰角被限制，无法转到底座下方。
  - 缩放距离下限 16 米，上限 80 米。

## 约束
- 整体视角下，画面上不出现铭牌以外的任何文字界面、按钮或菜单；加载页、简介卡片和驾驶位视角里的中控屏不受此限。
- 底座和展示台之外只有背景，不出现其他三维物件。
- 小路没有车辆信号灯；主路路口有信号灯。
- 车头朝向主路（背对便利店）。
- 镜头无法转到底座下方，缩放距离限制在 16 到 80 米之间。

## 例子
访客首次打开页面，看到右前上方俯视的微缩街角：
- 招牌写着「0xBB MART」，透过玻璃能看到店里的饮料柜和收银台。
- 店门前停着一辆打着双闪的红色保时捷，车头对着马路。
- 右侧小路上喷着「止まれ」。
- 展示台正面有铭牌。

访客滚轮一直往外滚，镜头停在距离 80 米处，不会再远；往下拖到底，镜头停在略高于底座边缘的高度，看不到底座底面。

## 验收
- [ ] 首屏默认视角下，展示台和铭牌完整可见。
- [ ] 场景中能找到便利店、保时捷、主路、小路、两条斑马线、两处「止まれ」路面字、倒三角「止まれ」标志。
- [ ] 保时捷位于店门前的车位上，车头朝主路。
- [ ] 小路方向没有车辆信号灯。
- [ ] 整体视角下，页面除铭牌外没有任何文字界面元素。
- [ ] 缩放距离被限制在 16 到 80 米之间；仰角限制使镜头无法低于底座。

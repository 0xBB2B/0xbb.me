# 加载页

## 目的
三维场景要加载几秒。这段时间让访客看到有内容在准备，并且可以不等待，先读个人资料。

## 逻辑
- 加载页是写在构建产物 `index.html` 里的静态网页内容，样式也内联在 `index.html` 中，脚本还没下载完时就能显示。
- 视觉：全屏深蓝色雨夜背景，中间显示名字 `FUBUKI_BB`、一行加载状态文字和一个循环的加载指示。
- 加载状态文字分两个阶段：
  - 下载代码阶段：中文「正在加载代码…」，英文 "Loading code…"；
  - 准备场景阶段：中文「正在布置雨夜街角…」，英文 "Setting up the rainy corner…"。
- 状态文字所在元素带 `role="status"` 和 `aria-live="polite"`。
- 加载页上有一个「先看资料」按钮（英文 "Read the profile first"）：
  - 点击后加载页立即移除，页面直接进入资料视角（`data-view="story"`），停在第 1 段起点；
  - 此时三维画面还没好，背景是深蓝径向渐变；
  - 场景在后台继续加载；画出第一帧后，三维画面在 450 毫秒内淡入，镜头位置对应当前滚动位置。
- 加载页文字语言按当前语言显示；脚本运行前（纯静态阶段）显示英文。
- 退出时机：
  - 场景画出第一帧后，加载页用 450 毫秒淡出，然后从页面移除，页面处于整体视角；
  - 点击「先看资料」时立即移除；
  - 三维画面失败时立即移除。
- 加载页显示期间，三维画面区域不可被键盘聚焦，并标记 `aria-busy="true"`。
- 三维场景不等招牌和铭牌用的网页字体：代码到了就建场景、画第一帧，招牌和铭牌先用系统字体绘制；网页字体下载完成后，招牌和铭牌贴图用网页字体重画一次。字体下载失败时一直用系统字体，场景照常可用。

## 约束
- 禁用 JavaScript 时打开 `index.html`，加载页的名字、状态文字和「先看资料」按钮都可见。
- 状态文字元素带 `role="status"` 与 `aria-live="polite"`。
- 场景首帧绘制后 450 毫秒内加载页完成淡出并被移除，`data-view` 为 `diorama`。
- 点击「先看资料」后加载页立即移除，`data-view` 为 `story`。
- 三维失败时加载页立即移除。
- 加载页显示期间三维画面区域带 `aria-busy="true"`，且不可聚焦。
- 系统「减少动态效果」设置不改变淡出、淡入时长。
- 网页字体文件迟迟下载不完（被挂起）时，场景仍能就绪（`aria-busy="false"`），不会因等字体而推迟。
- 网页字体下载完成后，铭牌贴图被重画（贴图内容更新）。

## 例子
- 一位网速很慢的中文访客打开页面：先看到深蓝背景上的「FUBUKI_BB」和「正在加载代码…」，几秒后变成「正在布置雨夜街角…」，再过一会儿加载页淡出，雨夜模型出现。
- 另一位访客等不及，点了「先看资料」：加载页消失，深蓝背景上出现第 1 段资料；他往下读到第 2 段时，三维画面淡入，镜头正对着便利店门面。

## 验收
- [ ] 构建产物 `index.html` 不执行脚本时包含加载页的名字、状态文字与「先看资料」按钮。
- [ ] 状态文字元素带 `role="status"` 和 `aria-live="polite"`。
- [ ] 两个阶段的状态文字与上文一致（中英文）。
- [ ] 首帧后加载页在 450 毫秒内淡出并从 DOM 移除，`data-view="diorama"`。
- [ ] 点击「先看资料」后加载页立即移除，`data-view="story"`，第 1 段可见。
- [ ] 点「先看资料」后场景就绪，三维画面在 450 毫秒内淡入。
- [ ] 加载期间三维画面区域带 `aria-busy="true"`。
- [ ] 挂起所有网页字体请求时，场景仍在代码加载完成后 3 秒内就绪。
- [ ] 放行字体请求后，铭牌贴图重画一次。

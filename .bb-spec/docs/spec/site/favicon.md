# 网站图标

## 目的
浏览器标签页上的图标与新站点主角（红色保时捷）一致。

## 逻辑
- 网站图标是一个 SVG 文件，画面为红色保时捷 911 的侧身剪影：
  - 车头朝右；
  - 能看出 911 标志性的斜背车顶线和尾翼轮廓；
  - 车身主色为红色 `#c8102a`，车轮为深色；
  - 背景透明。
- `index.html` 通过 `<link rel="icon" type="image/svg+xml">` 引用该文件。
- 图标在 16×16 像素下仍能看出是一辆车：剪影占满画布宽度的 80% 以上，不含文字和细线装饰。

## 约束
- 图标文件为 SVG，`index.html` 用 `type="image/svg+xml"` 引用。
- 图标主色为 `#c8102a`，背景透明。
- 图标不含 `<text>` 元素。
- 剪影宽度不小于画布宽度的 80%。
- 构建产物中包含该图标文件，引用路径可访问。

## 例子
访客打开 0xbb.me，浏览器标签页左侧显示一个红色跑车侧影的小图标，车头朝右，尾部能看到翘起的尾翼。

## 验收
- [ ] `index.html` 含 `<link rel="icon" type="image/svg+xml">` 且指向存在的 SVG 文件。
- [ ] SVG 中出现填充色 `#c8102a`。
- [ ] SVG 中没有 `<text>` 元素，也没有铺满画布的背景矩形。
- [ ] SVG 剪影的包围盒宽度不小于 `viewBox` 宽度的 80%。
- [ ] `dist/` 中包含该图标文件。

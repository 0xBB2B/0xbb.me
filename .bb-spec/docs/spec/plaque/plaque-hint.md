# 铭牌可点提示

## 目的
整体视角下画面上没有按钮，要让访客看出铭牌可以点，而且手机上没有悬停也能看出来。

## 逻辑
- 铭牌的黄铜边框一直在缓慢地明暗变化（呼吸微光）：
  - 一个周期 2.4 秒；
  - 亮度在「最暗」和「较亮」两档之间平滑往返；最暗时边框仍是正常的黄铜色，不会熄灭。
- 鼠标悬停（只在整体视角、且设备支持悬停 `hover: hover` 时生效）：
  - 从鼠标位置发出的射线最先碰到的是铭牌时，算作悬停在铭牌上；被其他物件挡住的部分不算；
  - 悬停时边框停止呼吸，保持最亮，亮度高于呼吸的「较亮」一档；
  - 三维画面 canvas 的 `cursor` 设为 `pointer`；
  - 鼠标移开后，边框恢复呼吸，`cursor` 恢复默认。
- 铭牌上的文字本身不发光、不闪动，只有边框变化。
- 离开整体视角后（进入资料视角或过渡中），悬停效果不生效，`cursor` 保持默认。
- 系统「减少动态效果」设置不改变呼吸微光。

## 约束
- 呼吸周期为 2.4 秒，最暗时边框亮度大于 0。
- 悬停在铭牌上时，边框亮度高于呼吸周期中的最大值。
- 悬停在铭牌上时 canvas `cursor` 为 `pointer`；移到铭牌以外恢复默认。
- 铭牌被其他物件挡住的部分，悬停不触发提示。
- 非整体视角下，悬停不改变 `cursor` 和边框亮度。
- 触屏设备（`hover: none`）上只有呼吸微光，没有悬停效果。

## 例子
- 访客打开页面，看到展示台正面的铭牌边框每 2.4 秒亮暗一次。
- 他把鼠标移到铭牌上：边框变得比呼吸时更亮，鼠标变成手形。
- 移到旁边的路面上：鼠标恢复箭头，边框接着呼吸。
- 手机访客看不到悬停效果，但能看到边框在呼吸。

## 验收
- [ ] 连续采样边框亮度，变化周期为 2.4 秒，最小值大于 0。
- [ ] 鼠标移到铭牌中心，canvas `cursor` 为 `pointer`，边框亮度高于呼吸最大值。
- [ ] 鼠标移到路面，`cursor` 恢复默认，边框恢复呼吸。
- [ ] 旋转到铭牌被挡住的角度，鼠标停在挡住铭牌的物件上时 `cursor` 不是 `pointer`。
- [ ] 资料视角下鼠标经过铭牌位置，`cursor` 不变。

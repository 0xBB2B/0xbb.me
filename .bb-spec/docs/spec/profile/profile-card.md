# 简介卡片

## 目的
三维画面还没加载好或无法运行时，访客照样能读到完整个人资料并打开链接。

## 逻辑
- 简介卡片是居中的模态对话框，内容全部是网页元素，不依赖 WebGL。
- 内容与中控屏一致，按顺序：头像 `profile.jpg`、名字、三个职位、所在地、四个方向、简介第一段、四个链接、「EN / 中」语言切换。
- 头像加载失败时，头像位置显示名字首字母「F」，其余内容照常显示。
- 弹出时机：
  1. 访客在加载页点击「先看资料」；
  2. 三维画面所需的代码加载失败；
  3. 创建 WebGL 失败；
  4. 运行中 WebGL 上下文丢失。
- 因第 2、3、4 种原因弹出时：
  - 卡片顶部显示一行提示：中文「3D 场景无法加载」，英文 "The 3D scene couldn't load"；
  - 卡片没有关闭按钮，按 Esc 也不关闭。
- 因第 1 种原因弹出时：
  - 卡片有关闭按钮，按 Esc 也能关闭；
  - 关闭后回到加载页，或加载已完成时回到整体视角；
  - 若在卡片打开期间三维画面失败，卡片切换为第 2～4 种的样式（出现提示、去掉关闭按钮）。
- 链接规则与中控屏相同：外部链接新标签页打开，Email 用 `mailto:`。

## 约束
- 卡片内容包含 8 项，与中控屏顺序一致。
- 头像加载失败时显示「F」占位，其余内容可读。
- 三维失败引起的卡片带失败提示、无关闭按钮、Esc 不关闭。
- 「先看资料」引起的卡片有关闭按钮、Esc 可关闭。
- 卡片打开期间三维失败，卡片立即显示失败提示并去掉关闭按钮。
- 卡片不显示技能详情和项目介绍。

## 例子
- 一位访客的浏览器禁用了 WebGL：加载页退出后直接弹出简介卡片，顶部写着「3D 场景无法加载」，下面是头像、名字、职位和简介；点击 LinkedIn 在新标签页打开；卡片没有关闭按钮。
- 另一位网速慢的访客在加载页点「先看资料」：读完后按 Esc 关闭，此时场景已加载好，看到整个微缩模型。

## 验收
- [ ] 点击「先看资料」弹出卡片，卡片有关闭按钮，Esc 可关闭。
- [ ] 模拟三维代码加载失败、WebGL 创建失败、上下文丢失，三种情况都弹出带失败提示的卡片。
- [ ] 失败卡片没有关闭按钮，按 Esc 不关闭。
- [ ] 模拟头像请求失败，头像处显示「F」。
- [ ] 卡片内容包含 8 项且顺序与中控屏一致。
- [ ] 「先看资料」卡片打开期间触发上下文丢失，卡片出现失败提示且关闭按钮消失。

# 术语表

> 全项目术语唯一权威源，仅 /spec 维护。跨语言 / 跨文档以英文锚点对齐；别名按需增补，只登记实际使用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| camera-stop | 资料视角里每段资料对应的镜头位置和观察目标，共 3 个 | 简体「停靠点」 |
| diorama-view | 镜头绕整个微缩模型旋转、缩放、平移的默认观察状态，页面不能滚动 | 简体「整体视角」 |
| loading-shell | 写在构建产物 `index.html` 中、脚本下载前即可显示的全屏加载画面 | 简体「加载页」 |
| plaque | 展示台正面刻有名字、职位、所在地三行文字，可点击进入资料视角的黄铜牌 | 简体「铭牌」 |
| pull-back-zone | 资料视角里第 1 段上方半个视口高的空白滚动区，滚到顶即回到整体视角 | 简体「回拉区」 |
| story-section | 资料视角里的一段网页文字，共 3 段，每段对应一个停靠点 | 简体「资料段」 |
| story-view | 点击铭牌后进入的观察状态：页面可上下滚动，镜头随滚动在停靠点间移动，并显示资料段 | 简体「资料视角」 |

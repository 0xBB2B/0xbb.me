# 术语表

> 全项目术语唯一权威源，仅 /spec 维护。跨语言 / 跨文档以英文锚点对齐；别名按需增补，只登记实际使用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| diorama-view | 镜头绕整个微缩模型旋转、缩放、平移的默认观察状态，页面不能滚动 | 简体「整体视角」 |
| loading-shell | 写在构建产物 `index.html` 中、脚本下载前即可显示的全屏加载画面 | 简体「加载页」 |
| neighbor-building | 便利店左侧、隔着小巷的两层楼，一楼是喫茶店，二楼住人 | 简体「旧楼」 |
| photo-print | 点小票上的头像后弹出的全身像，样子是一张贴着胶带、印着日期戳的冲印相片 | 简体「全身照相片」 |
| plaque | 展示台正面刻有名字、职位、所在地三行文字，可点击进入资料视角的黄铜牌 | 简体「铭牌」 |
| profile-page | 地址为 `/profile/`、不加载三维代码、只显示小票的独立页面 | 简体「独立资料页」 |
| receipt | 按便利店收银小票样式排版、写着站主资料的纸条卡片；资料视角、独立资料页和三维失败时共用同一张 | 简体「小票」 |
| story-view | 点击铭牌后进入的观察状态：镜头推到店门口，三维画面暂停刷新并变暗，显示小票；按 Esc 或「返回全景」按钮退出 | 简体「资料视角」 |

# 术语表

> 全项目术语唯一权威源，仅 /spec 维护。跨语言 / 跨文档以英文锚点对齐；别名按需增补，只登记实际使用过的语言写法。

| 锚点 | 定义 | 别名 |
|---|---|---|
| center-screen | 保时捷驾驶位右前方的屏幕，在驾驶位视角下以网页元素显示个人资料 | 简体「中控屏」 |
| diorama-view | 镜头绕整个微缩模型旋转、缩放、平移的默认观察状态 | 简体「整体视角」 |
| driver-view | 镜头位于保时捷驾驶座眼睛位置、只能小范围转头的观察状态 | 简体「驾驶位视角」 |
| instrument-cluster | 方向盘后方显示名字的仪表，属于三维画面的一部分 | 简体「仪表盘」 |
| loading-shell | 写在构建产物 `index.html` 中、脚本下载前即可显示的全屏加载画面 | 简体「加载页」 |
| plaque | 展示台正面刻有名字、职位、点车提示三行文字的黄铜牌 | 简体「铭牌」 |
| profile-card | 不依赖 WebGL、用网页元素显示完整个人资料的模态卡片 | 简体「简介卡片」 |

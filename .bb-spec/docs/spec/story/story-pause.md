# 资料视角下暂停三维

## 目的
访客读小票时，三维画面只当背景，不需要一直重画；停下来可以让显卡几乎不干活，电脑不发烫、风扇不狂转。

## 逻辑
- 进入资料视角、镜头到位、小票开始出现的同时，三维画面停止刷新：
  - 渲染循环不再画新帧，画布保留最后一帧；
  - 画布加上变暗和轻微模糊：亮度约 55%、饱和度约 80%、模糊约 1.5 像素，约 0.6 秒过渡到位。
- 暂停期间雨、双闪、信号灯等环境动效都停在当前画面，不在后台继续计算。
- 退出资料视角开始时，三维画面恢复刷新：
  - 变暗和模糊在约 0.6 秒内去掉；
  - 动画时间从暂停时的数值接着走，不把暂停的时长补进去，画面不跳变；
  - 镜头退回动画照常播放。
- 画质降档统计不计入暂停期间。
- 三维失败时本来就没有三维画面，不涉及本规则。

## 约束
- `data-view="story"` 且小票已出现后，连续 1 秒内 WebGL 的 draw 调用次数为 0。
- 资料视角下画布带变暗与模糊效果；整体视角下没有。
- 退出开始后 0.2 秒内恢复出现 draw 调用。
- 恢复后第一帧的动画时间与暂停前最后一帧的动画时间相差不超过 0.1 秒，不论暂停了多久。
- 在资料视角停留 10 秒再退出，画质档位不因这段时间改变。

## 例子
访客点铭牌进入资料视角，镜头推到店门口，小票掉下来的同时，身后的街景慢慢变暗、有点模糊，雨丝停在半空。他读了 2 分钟小票，任务管理器里显卡占用接近 0。他按 Esc，画面变亮，雨接着下，信号灯从刚才的颜色继续计时，镜头退回原来的角度。

## 验收
- [ ] 进入资料视角、小票出现后，统计 1 秒内 draw 调用为 0。
- [ ] 资料视角下画布的 CSS `filter` 含亮度与模糊；整体视角下没有。
- [ ] 按 Esc 后 0.2 秒内出现 draw 调用。
- [ ] 在资料视角停留 5 秒后退出，恢复后第一帧的 `uTime` 与暂停前相差 ≤ 0.1 秒。
- [ ] 资料视角停留 10 秒（期间注入慢帧也无效）后退出，`data-quality` 不变。

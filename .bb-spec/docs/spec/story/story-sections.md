# 资料段

## 目的
在资料视角下，分 3 段讲清楚站主是谁、在做什么、怎么联系，文字能选中复制，链接能打开。

## 逻辑
- 共 3 段，按顺序自上而下：

| 段 | 小标签 | 内容 |
|---|---|---|
| 第 1 段 | `01 · WHO` | 头像 `profile.jpg`（圆形）、名字 `FUBUKI_BB`、三个职位、所在地 `Tokyo · Shanghai` |
| 第 2 段 | `02 · ABOUT` | 标题 + 简介第一段 |
| 第 3 段 | `03 · FOCUS & LINKS` | 标题 + 四个方向 + 四个链接 |

- 文案：

| 项 | 中文 | 英文 |
|---|---|---|
| 职位 | 全栈工程师 · 系统架构师 · AI Agent开发者 | Full Stack Engineer · System Architect · AI Agent Developer |
| 第 2 段标题 | 雨夜里还亮着的店 | Still open on a rainy night |
| 第 3 段标题 | 一起出发 | Let's get going |
| 四个方向 | AI 工作流 / 可扩展后端 / 游戏 SDK 生态 / 支付平台 | AI Workflows / Scalable Backends / Game SDK Ecosystems / Payment Platforms |

- 简介只用站点数据里简介的第一段（中英文各一段）。
- 四个链接：GitHub `https://github.com/0xBB2b`、LinkedIn `https://www.linkedin.com/in/0xbb2b`、Juejin `https://juejin.cn/user/1037558235795032`、Email `mailto:bb@yorha.xyz`。外部链接在新标签页打开。
- 头像加载失败时，头像位置显示名字首字母「F」，其余内容照常显示。
- 排版：
  - 宽屏（宽高比 ≥ 1）：文字在视口左侧一栏，最大宽度 520 像素；文字后方有从左向右变淡的深色渐变，保证可读；
  - 竖屏（宽高比 < 1）：文字在视口下方约 45% 的区域，底下垫从下向上变淡的深色渐变。
- 附加元素（只在资料视角显示）：
  - 右侧竖排 3 个进度点，当前所在段的点高亮；
  - 第 1 段底部有 `SCROLL ↓` 提示；
  - 右上角固定的语言开关「EN / 中」，当前语言的按钮带 `aria-pressed="true"`；
  - 左上角固定的「返回全景」按钮（英文 "Back to overview"），点击等同按 Esc 退出资料视角；三维未就绪或失败时不显示。
- 可见性：只在资料视角（`data-view="story"`）下可见、可点击、可被键盘聚焦；其他状态下隐藏、`inert`、无法用 Tab 聚焦。
- 全站不显示技能详情和项目列表。

## 约束
- 3 段内容与顺序与上表一致，缺一不可。
- 简介只含第一段，不出现第二段内容。
- 链接 `href` 与上文一致；外部链接带 `target="_blank"` 和 `rel="noopener"`。
- 资料文字可被鼠标选中。
- 当前段的进度点高亮，另外两个不高亮。
- 语言开关只在资料视角出现；整体视角下 DOM 中没有可见的语言开关。
- 整体视角下，Tab 键无法聚焦到资料段中的链接。
- 页面中不出现技能详情和项目介绍文字。

## 例子
中文访客进入资料视角：
- 第 1 段左侧显示头像、「FUBUKI_BB」、「全栈工程师 · 系统架构师 · AI Agent开发者」和「Tokyo · Shanghai」，第 1 个进度点亮着，底部有 `SCROLL ↓`。
- 滚到第 2 段：标题「雨夜里还亮着的店」，下面是以「每一个界面背后，都藏着一个朴素的约定」开头的简介。
- 滚到第 3 段：标题「一起出发」，四个方向和 GitHub、LinkedIn、Juejin、Email 四个链接；点 GitHub 在新标签页打开。
- 他点右上角「EN」，3 段文字立即变成英文。

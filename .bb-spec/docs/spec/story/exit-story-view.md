# 退出资料视角

## 目的
看完资料的访客按 Esc 或点一个明确的按钮，就能回到整体视角继续转着看模型；滚动只用来翻资料，不会误退出。

## 逻辑
- 退出方式只有两种：按 Esc 键，或点击资料视角左上角的「返回全景」按钮（英文 "Back to overview"）。
- 在第 1 段往上滚动不会退出，也没有任何反应。
- 退出过程：
  1. 状态变为「退出中」：`<html data-view="exiting">`；
  2. 镜头从当前停靠点平滑移回进入前记下的整体视角，用时约 1 秒（不超过 1.2 秒）；资料段文字、进度点、语言开关、返回按钮同步淡出；
  3. 结束后状态变为整体视角：`data-view="diorama"`；页面回到顶部且不可滚动；旋转、缩放、平移恢复可用；资料段隐藏且 `inert`。
- 退出中忽略所有滚动、点击和按键；重复触发不叠加动画。
- 通过加载页「先看资料」进入资料视角的，没有进入前的整体视角可恢复，退回目标用默认视角（右前上方俯视整个模型）。
- 三维场景未就绪或已失败时，不显示「返回全景」按钮，按 Esc 也不退出，状态保持资料视角。
- 返回按钮只在资料视角下可点击、可聚焦；退出中随资料段一起淡出且不可点击、不可聚焦；进入中和整体视角下不显示。
- 退出不改变浏览器历史记录。

## 约束
- 资料视角下按 Esc 后 `data-view` 依次为 `exiting`、`diorama`，间隔不超过 1.2 秒。
- 点击「返回全景」按钮的效果与按 Esc 相同。
- 退出完成后镜头位置与进入前记下的位置距离不超过 0.1 米。
- 在第 1 段往上滚动后 `data-view` 仍为 `story`，滚动位置不变。
- 退出中按键、滚动、点击都不改变状态。
- 退出后整体视角下拖动能旋转模型，滚轮能缩放；资料段内链接无法被 Tab 聚焦。
- 三维未就绪或失败时，页面上没有可见的返回按钮，按 Esc 后 `data-view` 仍为 `story`。

## 例子
- 访客读到第 2 段，按了 Esc：文字淡出，镜头在 1 秒内退回他点铭牌前转到的那个侧面角度，`data-view` 从 `exiting` 变成 `diorama`，他又能拖着模型转了。
- 另一位访客用手机，点左上角「返回全景」，效果相同。
- 访客在第 1 段往上滑，页面不动，仍停在第 1 段。
- 一位 WebGL 不可用的访客看不到「返回全景」按钮，按 Esc 也没有反应。

## 验收
- [ ] 资料视角按 Esc 后 `data-view` 依次为 `exiting`、`diorama`，间隔 ≤ 1.2 秒，镜头与进入前位置距离 ≤ 0.1 米。
- [ ] 点击「返回全景」按钮后同样回到 `diorama`。
- [ ] 第 1 段往上滚动后仍为 `story`，`scrollY` 不变。
- [ ] 退出中按 Esc、滚轮不改变状态。
- [ ] 退出后拖动能改变镜头方位角，滚轮能改变镜头距离；资料段内链接无法被 Tab 聚焦。
- [ ] 模拟三维失败：没有可见的返回按钮，按 Esc 后仍为 `story`。
- [ ] 经「先看资料」进入、场景就绪后按 Esc，镜头回到默认视角位置（误差 ≤ 0.1 米）。

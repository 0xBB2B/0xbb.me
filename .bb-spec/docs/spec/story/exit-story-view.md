# 退出资料视角

## 目的
看完资料的访客只要往回滚到顶，就能回到整体视角继续转着看模型，不需要找按钮。

## 逻辑
- 第 1 段上方有一块回拉区，高度为半个视口，里面没有文字。
- 进入资料视角时，页面停在第 1 段起点（回拉区下沿），回拉区在视口上方看不见。
- 往上滚进回拉区时：
  - 镜头跟手，从第 1 停靠点向「进入前记下的整体视角」过渡，比例等于滚入回拉区的深度；
  - 资料段文字、进度点、语言开关、SCROLL 提示同步变淡，到顶时完全透明。
- 滚到顶（滚动位置为 0）时：
  - 镜头正好回到进入前的整体视角；
  - 状态变为整体视角：`data-view="diorama"`；
  - 页面恢复为不可滚动；旋转、缩放、平移恢复可用；
  - 资料段、进度点、语言开关隐藏且 `inert`。
- 在回拉区里没滚到顶就停手：滚动停止 150 毫秒后，页面平滑滚回第 1 段起点，镜头回到第 1 停靠点，文字恢复不透明。
- 通过加载页「先看资料」进入资料视角的，没有进入前的整体视角可恢复，退回目标用默认视角（右前上方俯视整个模型）。
- 三维场景未就绪或已失败时，回拉区照常存在，但滚到顶不退出，状态保持资料视角。
- 退出不改变浏览器历史记录。

## 约束
- 回拉区高度等于视口高度的一半。
- 滚入回拉区一半深度时，镜头位置在第 1 停靠点与整体视角之间，资料文字不透明度在 0 与 1 之间。
- 滚动位置到 0 时 `data-view` 变为 `diorama`，镜头位置与进入前记下的位置距离不超过 0.1 米。
- 回拉区内停手未到顶，1 秒后滚动位置回到第 1 段起点。
- 退出后整体视角下拖动能旋转模型，滚轮能缩放。
- 三维未就绪或失败时，滚到顶 `data-view` 仍为 `story`。

## 例子
- 访客在第 1 段往上滚了一点：镜头往后退，名字开始变淡；他停手，页面弹回第 1 段，名字重新清楚。
- 他再用力往上滚到顶：镜头退回他点铭牌前转到的那个侧面角度，文字全部消失，`data-view` 变成 `diorama`，他又能拖着模型转了。
- 一位 WebGL 不可用的访客滚到顶，停在空白的回拉区，页面仍是资料视角。

## 验收
- [ ] 回拉区高度等于 `innerHeight / 2`。
- [ ] 滚入回拉区一半时，资料文字不透明度介于 0 与 1 之间，镜头不在第 1 停靠点上。
- [ ] 滚到 0 后 `data-view="diorama"`，镜头与进入前位置距离 ≤ 0.1 米。
- [ ] 在回拉区中途停手，1 秒后滚动位置等于第 1 段起点。
- [ ] 退出后拖动能改变镜头方位角，滚轮能改变镜头距离。
- [ ] 退出后资料段内链接无法被 Tab 聚焦。
- [ ] 模拟三维失败，滚到 0 后 `data-view` 仍为 `story`。
- [ ] 经「先看资料」进入、场景就绪后滚到 0，镜头回到默认视角位置（误差 ≤ 0.1 米）。

# 退出资料视角

## 目的
看完小票的访客按 Esc 或点一个明确的按钮，就能回到整体视角继续转着看模型。

## 逻辑
- 资料视角下，画面左上角固定一个「返回全景」按钮（英文 "Back to overview"）。
- 退出方式只有两种：按 Esc 键，或点击「返回全景」按钮。全身照相片打开时按 Esc 只关闭相片，不退出。
- 滚轮、触摸滑动只滚动小票，不会退出。
- 退出过程：
  1. 状态变为「退出中」：`<html data-view="exiting">`；
  2. 小票、语言开关、返回按钮约 0.3 秒淡出；三维画面恢复刷新；
  3. 镜头从资料镜头位平滑移回进入前记下的整体视角，用时约 1 秒（不超过 1.2 秒）；
  4. 结束后状态变为整体视角：`data-view="diorama"`；旋转、缩放、平移恢复可用；小票隐藏且 `inert`。
- 退出中忽略所有滚动、点击和按键；重复触发不叠加动画。
- 三维场景失败时，不显示「返回全景」按钮，按 Esc 也不退出，状态保持资料视角。
- 返回按钮只在资料视角下可点击、可聚焦；退出中随小票一起淡出且不可点击、不可聚焦；进入中和整体视角下不显示。
- 退出不改变浏览器历史记录。

## 约束
- 资料视角下按 Esc 后 `data-view` 依次为 `exiting`、`diorama`，间隔不超过 1.2 秒。
- 点击「返回全景」按钮的效果与按 Esc 相同。
- 退出完成后镜头位置与进入前记下的位置距离不超过 0.1 米。
- 全身照相片打开时按 Esc，`data-view` 仍为 `story`，相片关闭。
- 资料视角下滚轮滚动后 `data-view` 仍为 `story`。
- 退出中按键、滚动、点击都不改变状态。
- 退出后整体视角下拖动能旋转模型，滚轮能缩放；小票内链接无法被 Tab 聚焦。
- 三维失败时，页面上没有可见的返回按钮，按 Esc 后 `data-view` 仍为 `story`。

## 例子
- 访客读完小票按了 Esc：小票淡出，身后街景变亮、雨接着下，镜头在 1 秒内退回他点铭牌前转到的那个侧面角度，`data-view` 从 `exiting` 变成 `diorama`，他又能拖着模型转了。
- 另一位访客用手机，点左上角「返回全景」，效果相同。
- 访客先点头像看全身照，按 Esc：只关掉相片，小票还在；再按一次 Esc 才退出资料视角。

## 验收
- [ ] 资料视角按 Esc 后 `data-view` 依次为 `exiting`、`diorama`，间隔 ≤ 1.2 秒，镜头与进入前位置距离 ≤ 0.1 米。
- [ ] 点击「返回全景」按钮后同样回到 `diorama`。
- [ ] 全身照相片打开时按 Esc，相片关闭，`data-view` 仍为 `story`。
- [ ] 资料视角下滚轮滚动后仍为 `story`。
- [ ] 退出中按 Esc、滚轮不改变状态。
- [ ] 退出后拖动能改变镜头方位角，滚轮能改变镜头距离；小票内链接无法被 Tab 聚焦。
- [ ] 模拟三维失败：没有可见的返回按钮，按 Esc 后仍为 `story`。

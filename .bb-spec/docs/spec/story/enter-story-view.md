# 进入资料视角

## 目的
访客在整体视角看够了模型，点一下铭牌，镜头推到店门口，一张写着站主资料的小票贴上来。

## 逻辑
- 触发方式（只在整体视角、且三维场景已就绪时有效）：
  1. 鼠标点击或手指轻点铭牌：射线最先命中铭牌才算，被遮挡不算；拖动旋转后松手不算点击；
  2. 键盘隐藏按钮「查看资料」（英文 "View profile"）：
     - 平时视觉上不可见；按 Tab 聚焦到它时，显示在画面左上角；
     - 按回车或空格，等同点击铭牌；
     - 读屏软件能读到它的名字；
     - 只在整体视角下可以聚焦。
- 进入过程：
  1. 记下当前整体视角的镜头位置和观察目标，退出时用；
  2. 页面状态变为「进入中」：`<html data-view="entering">`；
  3. 镜头从当前位置平滑移动到资料镜头位，用时不超过 1.5 秒。资料镜头位：镜头位置 `(10, 5.5, 36)`，观察目标 `(-2, -0.8, 4)`，从右前方较低处看展示台和便利店，铭牌和店头招牌完整入画；
  4. 到达后状态变为「资料视角」：`data-view="story"`；小票从画面上方掉下来；
  5. 键盘焦点移到小票里的名字 `FUBUKI_BB` 上。
- 进入中忽略所有点击、拖动、滚轮和按键；重复触发不会叠加动画。
- 进入资料视角后，整体视角的旋转、缩放、平移全部停用。
- 进入不改变浏览器历史记录，也不改变地址栏。

## 约束
- 只有射线最先命中铭牌的点击才触发；按下到松开之间移动超过 5 像素视为拖动，不触发。
- 从触发到 `data-view="story"` 不超过 1.5 秒。
- 进入中滚轮、按键、点击都不生效。
- 进入后 `history.length` 与地址栏不变。
- 进入后镜头与资料镜头位的距离小于 0.05 米。
- 进入后小票可见，`document.activeElement` 是小票里的名字元素。
- 隐藏按钮未聚焦时不可见；聚焦后在视口左上角可见；资料视角下无法聚焦到它。

## 例子
- 访客把模型转到侧面，然后点击铭牌：`data-view` 先变成 `entering`，镜头在 1.2 秒内平滑移到店门口前方低处，`data-view` 变成 `story`，一张小票从上方掉下来贴在画面左侧。
- 键盘用户按 Tab，左上角出现「查看资料」，按回车后同样进入，焦点落在小票里的「FUBUKI_BB」上。
- 访客按住铭牌拖动 30 像素再松手：只是旋转了模型，没有进入资料视角。

## 验收
- [ ] 点击铭牌后 `data-view` 依次为 `entering`、`story`，间隔不超过 1.5 秒。
- [ ] 进入中按 Esc、滚轮、点击，都不改变状态和镜头动画。
- [ ] 在铭牌上拖动超过 5 像素后松手，不进入资料视角。
- [ ] 进入前后 `history.length` 和 `location.href` 相同。
- [ ] Tab 聚焦隐藏按钮时它可见且在视口左上角，回车后进入资料视角。
- [ ] 进入后镜头与资料镜头位距离 < 0.05 米；小票可见；`document.activeElement` 是小票里的名字。

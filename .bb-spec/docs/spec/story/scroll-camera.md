# 滚动驱动镜头

## 目的
让访客用最熟悉的上下滚动来「走」过雨夜街角，每读一段资料，镜头就停在一个相应的位置。

## 逻辑
- 资料视角下，三维画面固定铺满视口，不随页面滚动；页面上滚动的是资料段。
- 3 个资料段各占一个视口高度，每段对应一个停靠点：

| 段 | 停靠点取景 |
|---|---|
| 第 1 段 | 从右前方较低处看展示台和便利店：铭牌和便利店招牌都完整入画 |
| 第 2 段 | 正对便利店门面：店头招牌完整入画，透过玻璃能看到店内 |
| 第 3 段 | 从保时捷侧前方较低处看车：整车完整入画，车后能看到店门 |

- 镜头跟手：滚动位置在第 k 段起点与第 k+1 段起点之间时，镜头位置和观察目标按两者之间的比例连续过渡（可带缓动），不跳变。
- 吸附：滚动停止 150 毫秒后，页面平滑滚到最近一段的起点，镜头随之停在对应停靠点。
- 取景区域：
  - 宽屏（视口宽高比 ≥ 1）：模型主体落在画面右侧约 60% 的区域，左侧留给资料文字；
  - 竖屏（宽高比 < 1）：模型主体落在画面上方约 55% 的区域，下方留给资料文字。
- 镜头视场角：视口宽高比 ≥ 1.6 时竖直视场角为 28°；宽高比 < 1.6 时加大竖直视场角，使水平视野等于宽高比 1.6、竖直 28° 时的水平视野；停靠点的镜头距离不随屏幕变窄而拉远。
- 资料视角下，滚轮、触摸滑动、键盘翻页（PageUp、PageDown、空格、方向键）都只改变页面滚动，不旋转或缩放模型。
- 系统「减少动态效果」设置不改变跟手和吸附。

## 约束
- 滚动位置正好在第 k 段起点时，镜头位置与第 k 停靠点的距离小于 0.05 米。
- 滚动位置在第 1、2 段起点正中间时，镜头位置到两个停靠点的距离都大于 0。
- 滚动停止 1 秒后，页面滚动位置等于离它最近的段起点。
- 宽屏在第 1 停靠点时，铭牌中心投影在画面横向 40% 以右；竖屏时，铭牌中心投影在画面纵向 55% 以上。
- 1440×900、390×844、375×667、800×800 下：第 1 停靠点铭牌与店头招牌完整入画；第 2 停靠点店头招牌完整入画；第 3 停靠点保时捷整车与店门完整入画。
- 资料视角下滚轮不改变镜头到观察目标的距离（只由滚动位置决定）。

## 例子
- 1440×900 的访客进入资料视角，看到第 1 段：左边是头像和名字，右边是展示台和便利店。
- 他慢慢往下滚到一半：镜头正在从展示台前往店门口移动，招牌越来越大。
- 他在 60% 处停手：0.15 秒后页面自动滚到第 2 段起点，镜头停在正对店门的位置。
- 手机竖屏访客在第 3 段：上半屏是从侧前方看过去的保时捷，车后是店门；下半屏是方向和链接。

## 验收
- [ ] 分别滚到 3 段的起点，镜头与对应停靠点的距离都小于 0.05 米。
- [ ] 滚到第 1、2 段中点，镜头不在任一停靠点上。
- [ ] 滚到第 1、2 段之间 60% 处停止，1 秒后滚动位置等于第 2 段起点。
- [ ] 1440×900 第 1 停靠点下，铭牌中心投影横坐标 > 视口宽度 40%。
- [ ] 390×844 第 1 停靠点下，铭牌中心投影纵坐标 < 视口高度 55%。
- [ ] 1440×900、390×844、375×667、800×800 下三个停靠点的主体（铭牌与招牌、招牌、整车与店门）包围盒完整在画面内。
- [ ] 宽屏第 3 停靠点整车左边缘投影 > 视口宽度 40%；竖屏第 3 停靠点整车下边缘投影 < 视口高度 55%。
- [ ] 第 3 停靠点镜头位于车头一侧（镜头 z 大于车身最前端 z），且偏向车身一侧。
- [ ] 资料视角下滚轮滚动后，镜头只随滚动位置变化，没有额外缩放。

# 退出驾驶位

## 目的
让访客随时能从车里回到整个微缩模型，并回到进车前看的角度。

## 逻辑
- 驾驶门内侧有一个门把手，平时带微弱的暖白色光；支持悬停的指针移上去时光标变手形、光变亮。
- 退出方式有三种，只在驾驶位视角、非过渡状态下生效：
  1. 点击或轻触内侧门把手；
  2. 按 Esc 键（焦点在中控屏内的输入元素上时也生效）；
  3. 触发浏览器返回（返回按钮、手机返回手势）。
- 退出过程依次为：
  1. 驾驶门向前打开约 65°；
  2. 镜头移到驾驶门外侧；
  3. 驾驶门关上；
  4. 镜头平滑回到进车前记下的整体视角（位置、朝向目标、缩放距离）。
- 从触发到镜头回到整体视角，总时长不超过 3.5 秒；过渡期间忽略所有输入。
- 通过门把手或 Esc 退出时，同时撤回进车时推入的那条浏览器历史，使历史记录回到进车前的状态；通过浏览器返回退出时不再额外撤回。
- 退出完成后恢复整体视角的旋转、缩放、平移操作，中控屏内容隐藏且不可被键盘聚焦。

## 约束
- 三种方式任一都能退出。
- 过渡期间的输入被忽略，重复触发不会叠加动画。
- 退出后镜头回到进车前的整体视角，位置误差不超过 0.1 米。
- 从触发到回到整体视角不超过 3.5 秒。
- 退出完成后 `history.length` 与 `history.state` 回到进车前的状态（门把手、Esc 两种方式）；浏览器返回方式下不额外调用返回。
- 退出后中控屏内容不可见、不可聚焦。

## 例子
- 访客在整体视角把镜头转到车的正后方，然后点车进入驾驶位。看完资料后点门把手：门打开，镜头出车、门关上，镜头回到车正后方的那个角度，用时 3 秒。
- 另一位手机访客在驾驶位用返回手势：同样退回整体视角，页面没有离开网站。
- 访客在退出过渡中连按 Esc：动画只播放一次。

## 验收
- [ ] 点门把手、按 Esc、调用 `history.back()` 三种方式均能退回整体视角。
- [ ] 退出后镜头位置与进车前记录值相差不超过 0.1 米。
- [ ] 从触发到回到整体视角不超过 3.5 秒。
- [ ] 过渡中重复按 Esc 只执行一次退出。
- [ ] 门把手或 Esc 退出后，`history.length` 行为与进车前一致（后续再按返回会离开或回到上一站点而非停留）。
- [ ] 退出后中控屏内元素无法通过 Tab 键获得焦点。
- [ ] 门把手悬停时光标为 `pointer`。

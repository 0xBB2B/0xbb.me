# 进入驾驶位

## 目的
把「看个人资料」变成「坐进车里」：点击保时捷后，镜头走到驾驶门、开门、坐进驾驶座。

## 逻辑
- 触发：在整体视角、非过渡状态下，点击或轻触保时捷车身任意部位（以射线最先命中的物体为准）。
- 保时捷是左舵车，驾驶门在车身左侧（以车头朝向为前方）。
- 过程依次为：
  1. 镜头从当前位置平滑移动到驾驶门外侧、约与车窗等高的位置；
  2. 驾驶门以前端为铰链向外打开约 65°；
  3. 镜头移入驾驶座眼睛位置，朝向正前方；
  4. 驾驶门关上。
- 从点击到门关上，总时长不超过 3.5 秒。
- 过程开始时记下进车前的整体视角（镜头位置、朝向目标、缩放距离），供退出时恢复。
- 过程开始时向浏览器历史推入一条记录，不改变页面地址的路径部分。
- 最终镜头：
  - 视口宽高比 ≥ 1：驾驶座视角，方向盘、仪表盘、中控屏同时完整入画；
  - 视口宽高比 < 1：镜头在驾驶座基础上向中控屏前移，让中控屏宽度不小于视口宽度的 60%。
- 进入驾驶位视角后，整体视角的旋转、缩放、平移操作全部停用。
- 键盘入口：页面上有一个「进入驾驶座」按钮（英文 "Take the driver's seat"），平时不可见；键盘 Tab 聚焦到它时显示在左上角，按回车或空格与点击保时捷效果相同。读屏软件能读到它的名称。只在整体视角、非过渡状态下可聚焦。

## 约束
- 只有命中保时捷才触发；点击其他物件或空白处不触发。
- 过渡期间忽略所有点击、拖动、滚轮和按键（包括 Esc 与再次点击）。
- 从点击到门关上不超过 3.5 秒。
- 过程开始时浏览器历史长度加 1，地址路径不变。
- 宽高比 ≥ 1 时方向盘、仪表盘、中控屏同时完整可见；宽高比 < 1 时中控屏宽度不小于视口宽度的 60%。
- 进入后整体视角的镜头操作停用。
- 「进入驾驶座」按钮未聚焦时不可见；聚焦时可见，按回车或空格进入驾驶位视角；驾驶位视角和过渡期间不可聚焦。

## 例子
- 1440×900 桌面访客点击保时捷车门：
  - 镜头绕到车左侧，驾驶门向前打开，镜头移进驾驶座，门关上，用时 3 秒。
  - 画面中能看到方向盘、仪表盘和右前方的中控屏，透过挡风玻璃能看到雨和马路。
  - 过渡中途按 Esc 没有反应。
- 390×844 竖屏手机访客轻触保时捷：进入后中控屏占画面宽度的七成左右。
- 键盘访客按 Tab，左上角出现「进入驾驶座」，按回车后镜头开始进车。

## 验收
- [ ] 点击车身进入驾驶位视角；点击路面或便利店不进入。
- [ ] 从点击到门关上用时不超过 3.5 秒。
- [ ] 过渡期间按 Esc、点击、拖动均无效果。
- [ ] 过程开始后 `history.length` 加 1，`location.pathname` 不变。
- [ ] 1440×900 下方向盘、仪表盘、中控屏同时完整位于视口内。
- [ ] 390×844 下中控屏宽度不小于视口宽度的 60%。
- [ ] 进入后滚轮和拖动不再旋转或缩放整体视角。
- [ ] Tab 聚焦「进入驾驶座」按钮时它可见，按回车后进入驾驶位视角；未聚焦时不可见。

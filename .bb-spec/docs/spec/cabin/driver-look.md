# 驾驶位转头

## 目的
坐在车里时可以小范围转头看看，增加沉浸感；同时不让镜头转到没有建模的后排和副驾。

## 逻辑
- 只在驾驶位视角、非过渡状态下生效。
- 镜头位置固定在驾驶座眼睛处，只改变朝向。
- 按住拖动（鼠标左键或单指）改变朝向：
  - 水平转动范围：以正前方为 0°，向左、向右各最多 30°；
  - 俯仰范围：以正前方为 0°，向上、向下各最多 15°；
  - 超出范围时停在边界。
- 松开后保持当前朝向，不自动回正。
- 滚轮、双指捏合、右键拖动都不产生效果，驾驶位视角没有缩放和平移。
- 在中控屏的网页内容上拖动（如滚动文字、选中文字）不触发转头。
- 每次进入驾驶位视角时，朝向重置为正前方（窄屏时为对准中控屏的朝向）。

## 约束
- 水平转动角度限制在 −30° 到 +30°。
- 俯仰角度限制在 −15° 到 +15°。
- 滚轮与双指捏合不改变镜头位置和视场角。
- 在中控屏内容上的拖动不改变镜头朝向。
- 每次进车时朝向回到初始朝向。

## 例子
- 访客坐进驾驶座后按住鼠标向左拖很远：镜头向左转到 30° 后停住，能看到驾驶门内侧，但看不到后排座椅。
- 松开鼠标，镜头停在 30°。
- 滚动鼠标滚轮，画面不变。
- 访客退出后再次进车：镜头朝向正前方。

## 验收
- [ ] 大幅向左或向右拖动后，水平角停在 ±30°。
- [ ] 大幅向上或向下拖动后，俯仰角停在 ±15°。
- [ ] 松开后朝向保持不变。
- [ ] 驾驶位视角下滚轮与捏合不改变镜头位置和视场角。
- [ ] 在中控屏文字上拖动选择文字时镜头不转动。
- [ ] 退出后再进车，朝向为初始朝向。

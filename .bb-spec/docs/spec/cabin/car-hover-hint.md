# 车辆悬停提示

## 目的
让有鼠标的访客一眼看出保时捷可以点击。

## 逻辑
- 只在整体视角、且不处于进出车过渡时生效。
- 指针落在保时捷车身（含车轮、尾翼、车窗）上时：
  - 光标变为手形（`pointer`）；
  - 车身轮廓线变为暖白色发光描边，比其他物件的描边更粗、更亮。
- 指针离开车身后，光标恢复默认，轮廓恢复为普通描边。
- 被其他物件挡住的部分不算悬停：以指针射线最先命中的物体为准。
- 只对支持悬停的指针生效（媒体查询 `hover: hover` 成立）；触屏设备上不出现发光描边。

## 约束
- 悬停在车身任意部位时光标为 `pointer`，离开后恢复默认。
- 悬停期间车身描边发光；离开后恢复。
- 指针射线先命中其他物件（如信号灯杆）时，不触发悬停。
- 驾驶位视角和进出车过渡期间不触发车辆悬停。
- `hover: hover` 不成立的设备不显示发光描边。

## 例子
- 访客用鼠标从便利店招牌移到保时捷尾翼上：光标变成手形，整辆车的轮廓亮起暖白色描边。
- 继续移到路面上：光标变回箭头，描边恢复。
- 访客把鼠标停在挡在车前的信号灯杆上，杆子后面正好是车：光标不变。

## 验收
- [ ] 指针移到车身上时 canvas 的 `cursor` 为 `pointer`，移开后恢复为默认。
- [ ] 悬停时车身描边颜色和粗细与未悬停时不同，离开后恢复。
- [ ] 指针射线先命中遮挡物时不触发悬停。
- [ ] 驾驶位视角下指针移动不改变车身描边。
- [ ] 模拟 `hover: none` 时不出现发光描边。

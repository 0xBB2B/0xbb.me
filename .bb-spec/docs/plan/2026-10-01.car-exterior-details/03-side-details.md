# 侧面细节

## 目标
车身两侧出现车门轮廓、门把手、黑色侧裙、侧窗分隔柱；每个车轮有五根轮辐、轮毂盖和红色卡钳。

## 业务规则（来源：spec car-side-details、diorama-layout）
- 门缝线每侧 3 条（2 竖 1 横），深红色，前后位置都在前后轮拱之间，凸出车身侧面不超过 1 厘米。
- 门把手每侧 1 个：长 10 到 16 厘米（场景实际尺寸，下同），前后位置在两条竖门缝线之间，高度在底部横线以上。
- 侧裙每侧 1 条：黑色，长不少于 1.3 米，高不超过 6 厘米，前后位置在两个轮胎之间，向外不超出轮胎外侧面。
- 侧窗分隔柱每侧 1 根：黑色，在侧窗的前后和高度范围内，离侧窗表面不超过 1 厘米。
- 每个车轮正好 9 个部件：轮胎 1、轮圈 1、轮辐 5、轮毂盖 1、卡钳 1。
- 5 根轮辐相邻夹角 72°（误差 2°），都在轮圈半径范围内；卡钳偏红，中心在轮心上方、轮圈半径范围内。
- 轮辐、轮毂盖、卡钳向外不超出轮胎外侧面 2 厘米；从车轮外侧上方往里看，先碰到的是车轮部件而不是车漆；车身不压住轮胎外侧面。
- 以上都不发光，材质颜色亮度低于 0.97；只有车漆有边缘光；整车俯视外廓宽 1.98 米、长 4.19 米（误差 5 厘米）。

## 成品定义
```ts
// 缩放前坐标；sz = ±1 是左右两侧
const line = toon('#7d1217');
// 门缝线 name 'door-line'（每侧 3 条）
box(car, 0.012, 0.42, 0.008, line, 0.64, 0.33, sz * 0.922)     // 前竖线
box(car, 0.012, 0.44, 0.008, line, -0.55, 0.33, sz * 0.922)    // 后竖线
box(car, 1.2, 0.012, 0.008, line, 0.045, 0.33, sz * 0.922)     // 底横线
// 门把手 name 'door-handle'
box(car, 0.14, 0.02, 0.012, line, -0.36, 0.7, sz * 0.924)
// 侧裙 name 'side-skirt'
box(car, 1.67, 0.045, 0.02, black, -0.025, 0.26, sz * 0.92)
// 侧窗分隔柱 name 'window-pillar'
add(car, new THREE.BoxGeometry(0.05, 0.3, 0.006), toon('#0c0d12'), -0.53, 1.01, sz * 0.68).rotation.z = 0.36

// 车轮：在每个车轮组 wg 里追加（wg 局部坐标，轮心在原点；sz 是该轮所在侧）
const silver = toon('#aab2c0');
// 轮圈位置由 sz * 0.14 收到 sz * 0.137，给外面三层腾出空隙；相邻两层之间至少留 1 毫米
// 'wheel-caliper'：BoxGeometry(0.16, 0.055, 0.002)，toon('#d8232f')，位置 (-0.113, 0.113, sz * 0.1492)，rotation.z = Math.PI / 4
// 'wheel-spoke' ×5：BoxGeometry(0.035, 0.23, 0.002)，silver；第 i 根 a = i * 2π / 5：
//     位置 (-Math.sin(a) * 0.115, Math.cos(a) * 0.115, sz * 0.1527)，rotation.z = a
// 'wheel-hub'：CylinderGeometry(0.045, 0.045, 0.002, 14)，silver，位置 (0, 0, sz * 0.1557)，rotation.x = Math.PI / 2
// 轮胎不变
```

## 函数清单
### diorama/car.ts
| 函数名 | 职责 |
|---|---|
| `buildCar`（修改） | 按成品定义新增门缝线、门把手、侧裙、分隔柱，并在每个车轮组里加轮辐、轮毂盖、卡钳 |

## 协作关系
只用 `box` / `add` 和 `toon`。不新增导出。

## 验证方式
- 测试入口：`buildCar()` 的 `group`（世界坐标；车宽方向是世界 x）。
- 网格名字与数量：`door-line` 6、`door-handle` 2、`side-skirt` 2、`window-pillar` 2、`wheel-spoke` 20、`wheel-hub` 4、`wheel-caliper` 4。车轮组是包含轮胎网格的那个组，每组直接子网格 9 个。
- 预期结果：上面「业务规则」每一条各至少一个用例；现有用例"每个车轮只有 2 个部件 / 没有轮辐、轮毂盖、卡钳"改成 9 个部件的新规则。
